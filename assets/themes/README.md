# Theme artwork

These four backgrounds were generated with OpenAI ImageGen on 2026-10-29 for
Download Engine. The application embeds them; no image service or internet
connection is required to use a theme.

- `neon-courier.jpg`: original adult anime courier in a violet and cyan city.
- `reactor-night.jpg`: original adult fantasy swordswoman and an emerald industrial city.
- `aurora.jpg`: original northern lights, mountains and lake.
- `moonveil.jpg`: a redesigned lunar sorceress with silver hair, violet magic and an observatory backdrop.

These illustrations were generated for the theme collection. They are not official
artwork or endorsements from a game franchise.

All artwork is 1672 × 941. The bundled files are JPEG (quality 90) re-encoded from
the generated PNGs to keep the installer small; re-encoding drops the PNGs' C2PA
content-credential chunk. Characters and bright scenery sit toward the right, so
the window crop keeps the right edge. The native UI darkens bright images enough
to keep text readable and uses an adjustable background strength.

User-supplied images stay in the local profile and are never uploaded. Imports
accept PNG/JPEG up to 16 MiB and 16 megapixels, resize to at most 2048 pixels per
side, and discard source metadata by re-encoding the decoded pixels.
