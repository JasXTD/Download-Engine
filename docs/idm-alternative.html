Free IDM alternative

A free, open-source alternative to Internet Download Manager

Download Engine is a free download manager for Windows, with a familiar layout inspired by Internet Download Manager (IDM). There is no trial or license key to manage, and the source code is open under the MIT license.

Before you switch

Honest answers.

Is it a complete replacement for IDM?+

Not completely. Download Engine covers everyday file and video downloads, but it does not offer complete IDM feature parity. Try it on the downloads you rely on before you switch.

Is Download Engine connected to IDM?+

No. Download Engine is an independent project. It is not affiliated with Internet Download Manager or its publisher.

Does it really cost nothing?+

Yes. The application is free and open source under the MIT license. Bundled components, including FFmpeg, have their own licenses.

Which systems does it run on?+

Windows x64, as an installer or a portable ZIP. macOS, Linux and Android packages are not provided.

How do I connect my browser?+

On Firefox, install the extension from Firefox Add-ons, then choose Connect browser in Tools → Browser setup. For Chrome, Edge and Brave, store approval is pending, so Browser setup shows how to load the extension manually for now.

Why does Windows show a warning?+

The Windows packages are currently unsigned, so Windows may show an unknown-publisher warning. Compare your download with the published SHA-256 checksums before you run it.
