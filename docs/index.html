Good to know

A little clarity.

Is Download Engine free?+

Yes. The application is free and open source under the MIT license. Bundled components, including FFmpeg, have their own licenses, available in About and the repository.

Can I use my own background image?+

Yes. Open Preferences → Appearance → Custom and choose Choose image…. PNG and JPEG files up to 16 MiB and 16 megapixels are supported. The app keeps a resized copy in your local profile; images are never uploaded. Your picture gets its own card next to the presets, and Remove image deletes the copy when you save. Read the custom themes guide.

Which hosting sites are supported?+

Since version 3.2.0, Download Engine supports individual MEGA public files and public WeTransfer transfers. It also discovers exposed links on supported download pages, including GitHub raw files. These features are included in the release packages. Password-protected transfers, account-only links and browser challenges are outside the supported workflows. See the hosting support details.

Can Web Grabber save any website?+

It can discover downloadable files and save supported static pages with their assets and local links. A saved copy does not reproduce server-side features, forms, sign-in flows or JavaScript applications. Site structure and access restrictions affect what can be saved.

Can it download every video?+

No. Built-in readers support selected public YouTube, Bilibili, TikTok and Twitch videos, plus compatible finished, unencrypted HLS and DASH streams from other sites. Live recording and DRM are unsupported. Website changes and access restrictions can affect availability. Check supported sites and limits.

Does it work on macOS or Linux?+

Current packages support Windows x64. macOS, Linux and Android packages are not provided.

Is this Internet Download Manager?+

Download Engine is an independent project inspired by Internet Download Manager (IDM). It is not affiliated with IDM and does not offer complete IDM feature parity.

How do I update?+

Choose Help → Check for updates to compare your version with the latest GitHub release, then open the release page to download it; installation stays manual. Close the app before upgrading. Preserve your data and downloads when updating a portable copy, and keep desktop and extension versions aligned. Older builds cannot write to a profile upgraded by version 3.4.0, so keep a backup if you may need to go back.
