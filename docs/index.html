A few things to know

Before you start.

Is Download Engine free?+

Yes. The application is free and open source under the MIT license. Bundled components, including FFmpeg, have their own licenses. You can read them in the app’s About screen or in the source repository.

Does it work on macOS or Linux?+

The current release supports Windows x64. macOS, Linux and Android packages are not provided.

Can it download every video?+

No. Support covers selected public video pages and supported finished, unencrypted HLS and DASH streams. Site changes and access restrictions can affect availability. Live recording and DRM-protected media are unsupported. Check the supported sites and limitations.

Is this Internet Download Manager?+

Download Engine is an independent project inspired by Internet Download Manager (IDM). It is not affiliated with IDM and does not offer complete IDM feature parity.

How do I update?+

Check the latest GitHub release. Close the app before upgrading. For portable copies, preserve your data and downloads when updating the same folder. Keep desktop and extension versions aligned. There is no automatic updater.
