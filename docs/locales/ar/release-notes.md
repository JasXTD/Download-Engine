## 3.0.2 — 2026-10-27

### سياسة الخصوصية

أُضيفت سياسة عامة توضح تكامل المتصفح والتخزين المحلي وملفات تعريف ارتباط تسجيل الدخول الاختيارية والاحتفاظ بالبيانات وحذفها والتكاملات الخارجية ومتطلبات الاستخدام المحدود في Chrome Web Store. يتضمن README ودليل نشر إضافات المتصفح روابط إليها، وتحتوي حزم المصدر والإضافات والإصدار المحمول والمثبت على نسخة منها. لم يتغير سلوك التنزيل أو الأذونات.

### مستودع المصدر وحزم الإصدارات

لم يعد الملف التنفيذي لـ FFmpeg خاضعًا للتتبع في مستودع المصدر. لا يزال برنامج التثبيت والإصدار المحمول يتضمنانه مع الشيفرة المصدرية المطابقة وإشعارات الترخيص. تبقى مصادر FFmpeg في Git، وتوضح تعليمات البناء كيفية الحصول على الملف التنفيذي المطابق.
