## 3.0.1 — 2026-10-27

### أيقونات إضافات المتصفح

تتضمن إضافات المتصفح الآن شعار Download Engine بأحجام مناسبة لشريط الأدوات والمتجر. تحتوي حزم Chrome وEdge وBrave وFirefox ومثبت Windows والإصدارات المحمولة على ملفات الأيقونات نفسها.

### إرشادات تثبيت إضافات المتصفح

يوضح README الآن أن موافقة متاجر الإضافات لا تزال قيد الانتظار. يتطلب Chrome وEdge وBrave تفعيل وضع المطور وتحميل الإضافة بعد فك ضغطها. يستخدم Firefox إضافة مؤقتة يجب تحميلها مجددًا بعد كل إعادة تشغيل للمتصفح. يتضمن قسم الإعداد روابط إلى خطوات التحميل والاتصال الخاصة بكل متصفح.
