## 3.1.0 — 2026-10-27

### تنزيل فيديو أسرع وعبء نقل أقل

تنزّل مقاطع الفيديو حتى 4 أجزاء بالتوازي مع احترام حدود الاتصال العامة أو الخاصة بالموقع إذا كانت أقل. يحتفظ الإيقاف المؤقت وإعادة المحاولة وإعادة تشغيل التطبيق بكل الأجزاء المكتملة والمتحقق منها، حتى إن اكتملت بغير ترتيب؛ وتُنزّل الأجزاء غير المكتملة مجددًا. تعرض نافذة الحالة الأجزاء والاتصالات النشطة. يقل العبء عبر تخزين الكتابات مؤقتًا وتقليل تحديثات التقدم وإعادة استخدام اتصال قاعدة البيانات. لا يزال الإيقاف المؤقت ينتظر اكتمال الكتابة وتُسجّل حصة البيانات بشكل دائم لكل كتلة مستلمة.

### حالة فشل أوضح

أصبحت تسمية الخطأ «فشلت» مع بقاء التفاصيل وإعادة المحاولة التلقائية كما هي.
