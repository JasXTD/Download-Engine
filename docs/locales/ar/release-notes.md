## 3.2.0 — 2026-10-28

### روابط المشاركة العامة

أُضيف دعم ملفات MEGA العامة المفردة وعمليات النقل العامة في WeTransfer. يفك MEGA التشفير محليًا ويتحقق من سلامة الملف. يعتمد الإيقاف المؤقت والاستئناف الآمن على دعم الخادم وهوية الملف.

لا تُدعم الروابط المحمية بكلمة مرور أو المقيدة بحساب أو المنتهية الصلاحية أو مجلدات MEGA.

### اكتشاف الملفات والتقاط التنزيلات في المتصفح

يكتشف التطبيق روابط الملفات في صفحات التنزيل، وتتطلب الخيارات الملتبسة والروابط إلى مواقع أخرى مراجعة. تحتفظ الإضافات بمفاتيح MEGA وتدعم تنزيل ملفات GitHub الخام. أعد تحميل الإضافات بعد الترقية.

### الموقع والوثائق

يعرض الموقع دعم الفيديو ومعاينات Web Grabber وتفاصيل خدمات الاستضافة وعرض شرائح للقطات الشاشة.

تتضمن حزم التثبيت والحزم المحمولة FFmpeg ومصادره المطابقة وتراخيصه.

أضيف إلى قائمة المساعدة التحقق اليدوي من إصدارات GitHub المستقرة وإعادة المحاولة وفتح صفحة الإصدار. تحتوي صفحة «حول» على رابط المستودع الرسمي في GitHub.
