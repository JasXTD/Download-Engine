# Download Engine

## بدء الاستخدام

تفتح التفضيلات في نافذة مقسمة إلى فئات. يطبق الحفظ التغييرات؛ ويلغي إلغاء أو × أو Escape التعديلات غير المحفوظة. يمكنك معاينة السمة، وإعادة الضبط تخص الفئة الحالية فقط. تحفظ المحررات المتقدمة بشكل منفصل وتعود إلى التفضيلات عند إغلاقها.

### بدء الاستخدام

اختر إضافة رابط من شريط الأدوات، وألصق رابط ملف مباشرًا، ثم راجع الاسم وقائمة الانتظار والمجلد وابدأ. تقبل إضافة دفعة رابطًا واحدًا في كل سطر. اختر «من نمط» لإنشاء روابط مرقّمة من رابط واحد يحتوي على *. اختر اللغة من الإعدادات ← المظهر ← اللغة. تتبع لغة النظام Windows وتستخدم الإنجليزية إذا لم تكن اللغة مدعومة.

## التنزيلات والاسترداد

### التنزيلات والاسترداد

انقر مرتين على التنزيل لعرض التقدم والسرعة والوقت المتبقي. الإيقاف المؤقت والإيقاف يحفظان البيانات. البدء فورًا يعطي الأولوية للملفات المحددة. يتطلب الاستئناف دعم الخادم والتحقق من تطابق الملف. حدّث الرابط المنتهي من قائمة الزر الأيمن. مسح المكتملة يزيل السجل فقط ويُبقي الملفات. من قائمة المهام، يحفظ «تصدير القائمة…» تنزيلاتك في ملف للنسخ الاحتياطي أو للنقل إلى كمبيوتر آخر، ويعرض «استيراد القائمة…» الجديد قبل إضافته؛ تُتخطى الروابط الموجودة وتبقى التنزيلات الجديدة متوقفة مؤقتًا. من قائمة عرض، يُظهر «مربع الإفلات العائم» مربعًا صغيرًا يبقى فوق النوافذ الأخرى؛ أفلت الروابط عليه لتنزيلها حتى عندما يكون Download Engine في علبة النظام.

## المواقع دون اتصال

### المواقع دون اتصال

استخدم أداة الجمع للعثور على الملفات أو حفظ موقع دون اتصال. حدد الرابط والعمق وحدود الصفحات والحجم، وراجع النتائج قبل الإضافة. افتح index.html المحفوظ للتصفح. الوظائف الديناميكية وتسجيل الدخول والنماذج والفيديو المشفر غير مدعومة. راجع العناصر المفقودة في التقرير.

## تكامل المتصفح

### تكامل المتصفح

افتح الأدوات ← إعداد المتصفح لتوصيل Chrome أو Edge أو Brave أو Firefox. يحتاج Chrome وEdge وBrave إلى معرّف الإضافة المثبتة الفعلي. استخدم التحقق من الاتصال في نافذة الإضافة. تحتوي خيارات المتصفح على اختيار لغة مستقل. يفتح زر الفيديو اختيار الجودة. تُستخدم بيانات دخول الموقع لهذا الملف فقط بعد موافقتك.

## قوائم الانتظار والجداول

### قوائم الانتظار والجداول

أدر قوائم الانتظار لتجميع الملفات وتحديد عدد التنزيلات المتزامنة. تنتظر القوائم الجديدة بدءها أو جدولتها. يدعم المجدول البدء والإيقاف والتكرار. يجب أن يظل التطبيق مفتوحًا، بما في ذلك في علبة النظام. يُفعّل الخروج وإيقاف الكمبيوتر أو وضعه في السكون أو الإسبات بشكل مستقل، ويمكن إلغاء العد التنازلي.

## البرمجة النصية

أصبح للمحرر والبرامج النصية المحمّلة تبويبان منفصلان. ابحث عن البرامج النصية أو أنشئها في القائمة، وافتح المحرر الكامل من عنوان محرر Lua أو PowerShell. تظهر أزرار الحفظ والتشغيل والإيقاف والسجلات الاختيارية مع الشفرة، وتوجد أوامر الملفات في قائمة إجراءات المحرر. يحافظ تبديل العرض على الشفرة غير المحفوظة والإعدادات وموضع المؤشر.


### البرمجة النصية

في الأدوات ← الأتمتة، أنشئ قواعد حسب الموقع أو امتداد الملف. في البرامج النصية اختر Lua أو PowerShell واحفظ ثم شغّل. المحفزات هي اليدوي وبدء التطبيق والفترة الزمنية واكتمال التنزيل أو القائمة. لا يتداخل البرنامج النصي مع نفسه. الإيقاف ينهيه لكنه لا يتراجع عن أوامر التنزيل المرسلة. راجع النتائج في السجل.

## برمجة Lua

### برمجة Lua

Lua مدمجة. أنشئ برنامج Lua نصيًا بمحفز يدوي واحفظ المثال التالي وشغّله. تعيد xd.queues() قوائم الانتظار، وxd.downloads() التنزيلات. يستخدم اكتمال التنزيل event.downloads واكتمال القائمة event.queue. لا تترجم أسماء الأوامر والحقول. المرجع الكامل في docs/automation.md. لا تطبع أسرارًا في السجلات. يعمل PowerShell بصلاحيات حساب Windows الخاص بك.

يفحص محررا Lua وPowerShell بناء الجملة تلقائيًا بعد توقف قصير عن الكتابة دون حفظ النص البرمجي أو تشغيله. أُضيفت أرقام الأسطر وتلوين بناء الجملة وأخطاء يمكن النقر عليها للانتقال إليها. اكتب بداية الاسم أو اضغط Ctrl+Space للاقتراحات، واختر بالأسهم وأدرج باستخدام Tab أو Enter أو النقر، وأغلق باستخدام Esc. يمكن التراجع عن الإكمال؛ تبقى أخطاء التشغيل في السجلات.

```lua
print("Hello from Lua!")
print("Trigger:", event.trigger)
for _, queue in ipairs(xd.queues()) do
    print(queue.name, "running:", queue.running)
end
for _, file in ipairs(event.downloads) do
    print("Finished:", file.name or file.id)
end
```

يشغّل المحفّز فشل التنزيل برنامجًا نصيًا عندما يظل التنزيل بحاجة إلى انتباه بعد إعادة المحاولة التلقائية في Download Engine، وعندها يتضمن event.downloads قيمة error لكل تنزيل. يعيد xd.retry(id) وxd.restart(id) المحاولة (يمكن للبرنامج النصي فعل ذلك 5 مرات لكل تنزيل)، ويعرض xd.notify(title, text) إشعار Windows، ويحفظ xd.store.get وxd.store.set القيم بين مرات التشغيل. لا يغيّر xd.rename وxd.move وxd.remove ملف التنزيل إلا عند تفعيل يمكنه تغيير الملفات المنزّلة. ويجرّب تشغيل بعينة… برنامج الحدث على التنزيلات التي تختارها، والتغييرات محاكاة فقط.

```lua
for _, file in ipairs(event.downloads) do
    if pcall(xd.retry, file.id) then
        print("Retrying:", file.name or file.id)
    else
        xd.notify("Download still failing", (file.name or file.id) .. ": " .. (file.error or "no details"))
    end
end
local handled = (xd.store.get("handled") or 0) + #event.downloads
xd.store.set("handled", handled)
print("Failed downloads handled:", handled)
```

لتحرير برنامج نصي في برنامج آخر، استخدم فتح ملف… وحفظ في ملف… في رأس المحرر. ينسخ فتح ملف… ملف ‎.lua أو ‎.ps1 إلى المحرر ويسألك أولًا إذا كان سيستبدل شيفرة غير محفوظة؛ اختر حفظ البرنامج النصي للاحتفاظ بها. ويكتب حفظ في ملف… الشيفرة الموجودة في المحرر في ملف.

### Lua Core API 1

أنشئ النص أو افتحه في Loaded scripts، واختر Lua وManual only في Script settings. يوسّع Full editor مساحة التحرير؛ اضغط Save script ثم Run script واقرأ Run logs. يعرض Core API وظائف المشغّل الحالي، ويفتح Ctrl+Space الاقتراحات. API 1 هو إصدار الواجهة وليس إصدار التطبيق. يحلل المثال HTML في الذاكرة فقط دون شبكة أو تنزيل؛ وتكون إمكانية جلب صفحة للنص اليدوي false.

```lua
-- Example: core-api
assert(xd.api_version == 1, "This example needs Lua API 1")
print("App:", xd.app_version, "Role:", xd.script_kind)
local html = '<a class="download" href="/files/demo.zip">Demo</a>'
local links = xd.html_select(html, "a.download[href]", "href")
local url = xd.url_join("https://example.com/catalog/", links[1])
print("Preview:", xd.to_json({ kind = "file", url = url }))
print("Can fetch a page:", xd.supports("xd.fetch"))
```

Open examples/core-api-automation.lua or examples/custom-site-reader.lua with Editor actions → Open file…. Site reader uses public pages, Pages patterns and Direct connection; test with Test on URL before enabling its trigger. Ordinary automation cannot call xd.fetch. Import script… accepts .de-script.json as a new draft with automatic triggers and file changes off; review its code and reselect local queues. Stop script does not undo submitted downloads. Full English reference: docs/automation.md.


## تكامل MCP

### تكامل MCP

في صفحة MCP، ابدأ خادم HTTP المحلي وانسخ إعدادات العميل. ابدأ بوضع العرض فقط. يحتاج عميل الذكاء الاصطناعي إلى الرابط وترويسة المصادقة السرية. لا تنشر الرمز. أوقف الخادم أو غيّر الرمز لإلغاء الوصول. التفاصيل في docs/mcp-ai-guide.md.

يفتح MCP الآن في نافذة منبثقة من شريط الأدوات أو قائمة الأدوات أو التفضيلات مع بقاء الصفحة الحالية. إغلاقها باستخدام × أو Escape لا يوقف الخادم ويحتفظ بتعديلات MCP غير المحفوظة. استخدم إيقاف الخادم لفصل عملاء الذكاء الاصطناعي. عند فتحها من التفضيلات، يعيدك إغلاقها إلى المسودة نفسها.

## فحص مضاد الفيروسات

الماسح: Microsoft Defender, Malwarebytes, Kaspersky, Bitdefender, ClamAV.

يتطلب تكامل برنامج مكافحة الفيروسات الإنجليزي مع المستكشف. المهلة تخص التسليم لا الفحص. ألغِ الفحوص داخل برنامج مكافحة الفيروسات.

يلزم مجلد التثبيت الافتراضي.

يتحكم برنامج مكافحة الفيروسات في الحماية والعزل. إرسال الطلب لا يعني خلو الملف من التهديدات.

التحقق من الإعداد: تم العثور على التكامل؛ يُتحقق من توفر الفحص عند طلبه.

### فحص مضاد الفيروسات

افتح الأدوات ← فحص الفيروسات. اختر فردي لتنزيل مكتمل واحد أو دفعة لعدة ملفات. يمكن إلغاء الفحص الفردي. تُقفل علامات التبويب أثناء الفحص أو انتظار مراجعة نتائج Malwarebytes / Kaspersky / Bitdefender.

اختر الماسح في الإعدادات ثم افتح الأدوات ← فحص الفيروسات ← دفعة. حدد ملفات مكتملة وابدأ وراجع النتائج. يلغي الإيقاف الطلبات التي لم تُرسل. ينتظر Malwarebytes / Kaspersky / Bitdefender مراجعتك بعد كل طلب. أوقف الفحوص المسلّمة داخل Malwarebytes / Kaspersky / Bitdefender. طلب الفحص لا يعني أن الملف آمن.

## الإعدادات والسجلات

### الإعدادات والسجلات

تشمل الإعدادات اللغة والسمة والمجلدات والسرعة والحصص والوكيل وعدد الاتصالات. تتيح السجلات البحث والتصفية والنسخ وفتح المجلد وتصدير التشخيص. تحتفظ الروابط والمسارات ومخرجات البرامج النصية والأخطاء التقنية بالنص الأصلي. راجع التقرير قبل مشاركته.

تتحقق النسخة المثبتة من مجلد التنزيلات الحالي المسجل في Windows عند كل تشغيل، بما في ذلك نقله إلى قرص آخر. تستخدم التنزيلات الجديدة هذا الموقع، بينما تبقى التنزيلات الحالية والتقدم المحفوظ والمجلدات المختارة كما هي. تحدد النسخة المحمولة المجلد الافتراضي حسب موقع التطبيق عند كل تشغيل. تحتفظ الملفات الشخصية القديمة باسم المجلد الفرعي IDM EX. يظهر خطأ إذا تعذر تحديد الموقع.

## استكشاف الأخطاء

### استكشاف الأخطاء

عند فشل الاتصال، تحقق من تشغيل التطبيق ومعرّف الإضافة وتسجيلها. بعد التحديث أعد تحميل الإضافة والصفحة. إذا فشل التنزيل، افحص مساحة القرص وأذونات المجلد والوكيل وصلاحية الرابط. لا تحذف بيانات الاسترداد قبل محاولة الاستئناف. إذا ظهرت مربعات بدل الحروف، أضف خطوط اللغة في Windows ثم أعد تشغيل التطبيق.
