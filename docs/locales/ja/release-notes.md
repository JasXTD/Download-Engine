## 3.0.1 — 2026-10-27

### ブラウザー拡張機能のアイコン

ブラウザー拡張機能に、ツールバーとストア向けの Download Engine ロゴを追加しました。Chrome、Edge、Brave、Firefox のパッケージ、Windows インストーラー、ポータブル版に同じアイコンファイルが含まれます。

### ブラウザー拡張機能の導入手順

README に、ブラウザーストアの承認待ちであることを明記しました。Chrome、Edge、Brave ではデベロッパーモードで展開済みの拡張機能を読み込みます。Firefox では一時的なアドオンとして読み込み、ブラウザーの再起動後に再度読み込む必要があります。設定の項目から、各ブラウザーの読み込みと接続手順を確認できます。
