## 3.15.0 — 2026-11-06

### Lua プロバイダーのコア機能と ASS 字幕

Lua HTTP に HEAD、PUT、PATCH、DELETE、OPTIONS、サイズ制限付きバイナリ本文、および明示的に渡す単一オリジン限定のセッションを追加しました。認証情報はリゾルバーの外では暗号化され、プランに保存されたりオフライン処理側に渡されたりしません。メディアプランはサイズ不明のセグメントに対応し、lua_stream は上限付きのチャンクと検証済みチェックポイントを使って、一時停止、再開、停止、障害からの復旧を支えます。

OS で保護されたバイナリ/RSA 認証情報のインポート、乱数バイト、SHA-1/SHA-256、HMAC、RSA 署名・復号、AES ブロック復号を追加しました。ASS 字幕のスタイルとインライン指定は MKV では保持され、MP4 ではテキスト字幕に変換されます。新しい認証情報やメディア機能を使うプロファイルには、書き込みバージョン 9 に対応したアプリが必要です。既存のチェックポイント形式との互換性は維持されます。

オフライン CENC 作成者向けラボでは、Lua による限定的な AVC/AAC サンプル暗号化の解析、模擬の署名付きライセンス交換、鍵の受け渡し、復号済みトラックと ASS 字幕の多重化を実演します。サイト認証、ライセンス形式、コンテナ解析は Lua 側の役割です。検証は生成データだけを使い、実サービスや実アカウントは使用しません。完全な CENC 実装ではありません。

### トレントの共有と検索

完了したトレントの共有は、共有比 2.0 に達するか 1 週間たつか、どちらか早いほうで自動的に停止するようになりました。この設定は既存のプロファイルも含めて初期状態で有効で、どちらの上限も環境設定 → トレントで変更またはオフにできます。ダウンロード中のアップロードも共有比に数えます。状態ウィンドウに共有比が表示され、上限で停止したトレントはファイルを残したまま、メニューの再度共有で共有を再開できます。

トラッカーのないマグネットリンクも、そのまま拒否されることはなくなりました。ダウンロードを追加の画面では、DHT 検索によってどのトレントを探しているかと IP アドレスが他のコンピューターに見えることを説明し、DHT で検索をクリックした後にだけ検索します。確認済みのファイル一覧で公開トレントと分かるまで、このコンピューターをピアとして通知しません。プライベートトレントの場合は検索を停止し、検索は 10 分で終了します。ブラウザー、クリップボード、エクスプローラーからのリンクが自動で検索することはありません。

ルーターを自動設定 (UPnP) が新たに加わりました。必要となる着信接続と同じく、初期状態ではオフです。プライベートネットワークの既定のゲートウェイとだけ通信し、1 時間ずつ有効な転送ルールを 1 つだけ要求して、削除するのは自身のルールだけです。macOS では利用不可と表示されます。見つかったピアや DHT ノードのうち、他のサービスのポート（1024 未満や SIP 5060 など）を使うものには接続しません。DHT が原因で停止したダウンロードは、その理由を選択した言語で表示するようになりました。

## 3.5.1 — 2026-10-29

### Lua プロバイダーのセキュリティ

- resolve/refresh と transform/finish は権限を分離したワーカープロセスで実行されます。処理側ではソース読み込み時も `xd.fetch` を利用できません。初期化は `xd.phase` で分岐してください。解決側のローカル変数は処理側に引き継がれません。
- 保存する計画はサイズ、ハッシュ、変換識別子のみです。解決済み URL は必要時に更新し、ジョブに固定したソースは現在の Windows ユーザーの DPAPI で保護します。既存ジョブはチェックポイントの結び付きを維持して原子的に更新され、旧版からの書き込みは拒否されます。
- `xd.key` と、リダイレクトされた標準入力から鍵を読む `scripts protect-key` により、プロバイダーに結び付いた不透明な AES 鍵ハンドルを利用できます。秘密鍵をソースやエクスポートに含める必要はありません。過去のバックアップやライブラリ内の既存の鍵リテラルは消去されません。詳細は `docs/lua-providers.md` を参照してください。

### 履歴を消去

完了履歴を消去する前に、キューと完了件数を示す確認画面が表示されます。キャンセルまたは閉じると履歴は保持されます。ダウンロードしたファイルは削除されません。
