## 3.0.2 — 2026-10-27

### プライバシーポリシー

ブラウザー連携、ローカル保存、任意のブラウザーログイン Cookie、データの保持と削除、外部ツールとの連携、Chrome ウェブストアの限定的使用要件を説明する公開プライバシーポリシーを追加しました。README とブラウザー公開ガイドにリンクを掲載し、ソース、拡張機能、ポータブル版、インストーラーの各パッケージにも同梱します。ダウンロードの動作と権限は変わりません。

### ソースリポジトリとリリースパッケージ

FFmpeg の実行ファイルをソースリポジトリの管理対象から外しました。インストーラーとポータブル版には、引き続き実行ファイル、対応するソースコード、ライセンス表記を同梱します。FFmpeg のソースコードは Git に残し、ビルド手順に対応する実行ファイルの入手方法を記載しました。
