## 3.6.0 — 2026-10-31

### 拡張機能

新しい「拡張機能」ページが「スクリプト」ページに代わり、インストール済み、スクリプト、ルール、実行履歴のタブを備えます。拡張機能は 1 つの .de-extension.json ファイルで、サイトリーダー、ダウンロードプロバイダー、自動化タスクをまとめます。インストールはローカルファイルからのみで、配布元は確認されません。確認画面でできることを確認でき、インストール直後は無効です。更新で新しいアクセスが必要な場合は必ず確認します。Web アクセスは宣言されたホストに限られます。最初の拡張機能をインストールすると、旧版アプリはこのプロファイルに書き込めなくなります。

## 3.5.2 — 2026-10-30

### 起動時に更新を確認

初期設定ではアプリを開くたびに一度確認します。新しいバージョンがあると更新を入手するか後で行うかを選べます。オフラインのエラーは表示せず、環境設定で無効にできます。 公式 GitHub リリースページから更新をダウンロードしてインストールしてください。

## 3.5.1 — 2026-10-29

### Lua プロバイダーのセキュリティ

- resolve/refresh と transform/finish は権限を分離したワーカープロセスで実行されます。処理側ではソース読み込み時も `xd.fetch` を利用できません。初期化は `xd.phase` で分岐してください。解決側のローカル変数は処理側に引き継がれません。
- 保存する計画はサイズ、ハッシュ、変換識別子のみです。解決済み URL は必要時に更新し、ジョブに固定したソースは現在の Windows ユーザーの DPAPI で保護します。既存ジョブはチェックポイントの結び付きを維持して原子的に更新され、旧版からの書き込みは拒否されます。
- `xd.key` と、リダイレクトされた標準入力から鍵を読む `scripts protect-key` により、プロバイダーに結び付いた不透明な AES 鍵ハンドルを利用できます。秘密鍵をソースやエクスポートに含める必要はありません。過去のバックアップやライブラリ内の既存の鍵リテラルは消去されません。詳細は `docs/lua-providers.md` を参照してください。

### 履歴を消去

完了履歴を消去する前に、キューと完了件数を示す確認画面が表示されます。キャンセルまたは閉じると履歴は保持されます。ダウンロードしたファイルは削除されません。

## 3.5.0 — 2026-10-29

### Lua Provider API 1

Lua ダウンロードプロバイダーで取得元の解決、バイト処理、ハッシュ検証と通常の一時停止・再開ができます。各ダウンロードは保存時のスクリプト版を保持します。検証はローカル生成の暗号化ファイルのみです。プロバイダー保存後は旧版アプリがこのプロファイルに書き込めなくなります。

## 3.4.1 — 2026-10-29

大きなキューでのレコードのコピーと検索の重複処理を削減しました。小さいウィンドウではファイル名の表示領域が広がります。キューの状態の横から開始・一時停止できます。開始はスケジュールを上書きします。状態にカーソルを合わせると再試行の説明やエラーを確認できます。転送、検証、再開用データ形式は変更していません。

## 3.4.0 — 2026-10-29

### テーマコレクション

環境設定 → 外観 → カスタムで Neon Courier、Reactor Night、Aurora、Moonveilを選べます。背景の強さやアクセントを調整し、PNG/JPEG も取り込めます。保存で適用し、キャンセルで元に戻します。画像はサイズ制限付きでバックグラウンド処理され、ローカルに保存されます。

### プロファイルと制御の改善

プロファイルのバージョン保護と MCP アクセス制御も含まれます。
