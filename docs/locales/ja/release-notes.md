## 3.2.0 — 2026-10-28

### 公開共有リンク

MEGA の公開単一ファイルと WeTransfer の公開転送に対応しました。MEGA はローカルで復号し、整合性を検証します。一時停止と再開はサーバーの対応とファイルの同一性に応じて安全に行われます。

パスワード保護、アカウント限定、期限切れの転送や MEGA フォルダーは非対応です。

### ダウンロードページの検出とブラウザー連携

ダウンロードページから公開ファイルリンクを検出し、候補が曖昧な場合や別サイトへのリンクは確認を求めます。拡張機能は MEGA のキーを保持し、GitHub の raw ファイルのダウンロード操作に対応します。更新後は拡張機能を再読み込みしてください。

### ウェブサイトとドキュメント

ウェブサイトに動画対応、Web Grabber のプレビュー、共有サイトの詳細とスクリーンショットのスライドショーを追加しました。

インストーラーとポータブル版には FFmpeg と対応するソース、ライセンスが含まれます。

ヘルプに GitHub の安定版を手動確認、再試行、リリースページを開く機能を追加しました。アプリ情報から公式 GitHub リポジトリを開けます。
