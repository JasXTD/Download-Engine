## 3.2.0 — 2026-10-28

### 공개 공유 링크

MEGA 공개 단일 파일과 WeTransfer 공개 전송을 지원합니다. MEGA는 로컬에서 복호화하고 무결성을 검증합니다. 서버 지원과 파일 식별 정보가 일치할 때 안전하게 일시 중지하고 재개할 수 있습니다.

암호 보호, 계정 전용, 만료된 전송 및 MEGA 폴더는 지원하지 않습니다.

### 다운로드 페이지 파일 검색과 브라우저 캡처

다운로드 페이지에서 공개 파일 링크를 찾으며, 모호하거나 다른 사이트로 연결되는 항목은 검토가 필요합니다. 확장 기능은 MEGA 키를 유지하고 GitHub 원본 파일 다운로드 동작을 지원합니다. 업데이트 후 확장 기능을 다시 로드하세요.

### 웹사이트와 문서

웹사이트에 동영상 지원 정보, Web Grabber 미리보기, 공유 사이트 설명과 스크린샷 슬라이드쇼를 추가했습니다.

설치 및 포터블 패키지에는 FFmpeg와 해당 소스 및 라이선스가 포함됩니다.

도움말에 GitHub 안정 버전 수동 확인, 재시도 및 릴리스 페이지 링크를 추가했습니다. 정보 화면에서 공식 GitHub 저장소를 열 수 있습니다.
