## 3.1.0 — 2026-10-27

### 더 빠른 동영상 다운로드와 전송 부하 감소

동영상은 최대 4개 구간을 병렬로 다운로드하며 더 낮은 전역 또는 사이트별 연결 제한을 따릅니다. 일시 중지, 재시도, 앱 재시작 후에도 순서와 관계없이 완료되고 검증된 구간은 유지하며 미완료 구간은 다시 받습니다. 상태 창에 활성 구간과 연결 수를 표시합니다. 디스크 쓰기 버퍼링, 진행률 갱신 빈도 조정, 데이터베이스 연결 재사용으로 부하를 줄입니다. 중지 시 쓰기 완료를 기다리며 수신한 데이터 조각마다 할당량을 영구 기록합니다.

### 더 명확한 실패 상태

실패 상태는 “실패”로 표시하며 오류 세부 정보와 자동 재시도는 그대로입니다.
