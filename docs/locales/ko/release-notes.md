## 3.5.1 — 2026-10-29

### Lua 공급자 보안

- resolve/refresh와 transform/finish가 권한을 분리한 작업자 프로세스에서 실행됩니다. 처리 작업자에는 소스를 불러올 때도 `xd.fetch`가 제공되지 않습니다. 단계별 초기화에는 `xd.phase`를 사용하세요. 해석 단계의 지역 변수는 처리 단계로 전달되지 않습니다.
- 저장된 계획에는 크기, 해시, 변환 식별자만 남습니다. 해석된 URL은 필요할 때 갱신하고 작업에 고정된 소스는 현재 Windows 사용자의 DPAPI로 보호합니다. 기존 작업은 체크포인트 연결을 유지하며 원자적으로 업그레이드되고 이전 버전의 쓰기는 차단됩니다.
- `xd.key`와 리디렉션된 표준 입력에서 키를 읽는 `scripts protect-key`는 공급자에 연결된 불투명 AES 키 핸들을 제공합니다. 비밀 키를 소스나 내보내기 파일에 넣을 필요가 없습니다. 과거 백업과 라이브러리의 기존 키 리터럴은 삭제되지 않습니다. `docs/lua-providers.md`를 참고하세요.

### 기록 지우기

완료 기록을 지우기 전에 대기열과 완료 개수를 보여 주는 확인 창이 표시됩니다. 취소하거나 닫으면 기록이 유지됩니다. 다운로드한 파일은 삭제되지 않습니다.

## 3.5.0 — 2026-10-29

### Lua Provider API 1

Lua 다운로드 공급자로 소스 확인, 바이트 처리, 해시 검증 및 일반 일시 중지/재개를 사용할 수 있습니다. 각 다운로드는 저장된 스크립트 버전을 유지합니다. 로컬에서 생성한 암호화 파일로만 검증했습니다. 공급자를 저장하면 이전 앱 버전은 이 프로필에 쓸 수 없습니다.

대규모 대기열에서 레코드 복사와 중복 검색을 줄였습니다. 작은 창에서는 파일 이름에 더 많은 공간을 제공합니다. 대기열 상태 옆에서 시작하거나 일시 중지할 수 있으며 시작은 예약을 재정의합니다. 상태에 마우스를 올리면 재시도 설명과 오류가 표시됩니다. 전송, 검증 및 이어받기 형식은 변경되지 않았습니다.
