## 3.15.0 — 2026-11-06

### Lua 공급자 핵심 기능과 ASS 자막

Lua HTTP에 HEAD, PUT, PATCH, DELETE, OPTIONS, 크기가 제한된 바이너리 본문과 명시적으로 전달하는 단일 출처 전용 세션을 추가했습니다. 자격 증명은 리졸버 밖에서 암호화된 상태로 유지되며 계획에 저장되거나 오프라인 처리기에 전달되지 않습니다. 미디어 계획은 크기를 알 수 없는 세그먼트를 지원하며, lua_stream은 제한된 청크와 검증된 체크포인트로 일시 중지, 재개, 중지 및 복구를 지원합니다.

운영체제로 보호되는 바이너리/RSA 자격 증명 가져오기, 무작위 바이트, SHA-1/SHA-256, HMAC, RSA 서명과 복호화 및 AES 블록 복호화를 추가했습니다. ASS 자막의 스타일과 인라인 지정은 MKV에서 유지되고 MP4에서는 텍스트 자막으로 변환됩니다. 새 자격 증명이나 미디어 기능을 사용하는 프로필에는 쓰기 버전 9를 지원하는 앱이 필요합니다. 기존 체크포인트 형식은 계속 호환됩니다.

오프라인 CENC 제작자 실습은 Lua로 제한된 AVC/AAC 샘플 암호화 형식을 분석하고, 합성된 서명 라이선스 교환, 키 전달 및 복호화된 트랙과 ASS 자막의 다중화를 보여 줍니다. 사이트 인증, 라이선스 형식과 컨테이너 파서는 Lua에서 구현해야 합니다. 검증에는 생성된 데이터만 사용하며 실제 서비스나 계정을 사용하지 않습니다. 완전한 CENC 구현은 아닙니다.

### 토렌트 공유 및 검색

완료된 토렌트 공유는 이제 공유 비율 2.0 또는 1주 중 먼저 도달하는 시점에 자동으로 중지됩니다. 기존 프로필을 포함해 기본적으로 켜져 있으며, 두 한도 모두 환경 설정 → 토렌트에서 변경하거나 끌 수 있습니다. 다운로드 중 업로드도 공유 비율에 포함됩니다. 상태 창에 공유 비율이 표시되고, 한도로 중지된 토렌트는 파일을 유지하며 메뉴에서 다시 공유를 제공합니다.

트래커가 없는 마그넷 링크를 더 이상 그냥 거부하지 않습니다. 다운로드 추가 창은 DHT 검색 시 어떤 토렌트를 원하는지와 IP 주소가 다른 컴퓨터에 보인다는 점을 설명하고, DHT에서 검색을 클릭한 후에만 검색합니다. 확인된 파일 목록이 공개 토렌트임을 보여 준 후에야 이 컴퓨터를 피어로 알립니다. 비공개 토렌트이면 검색이 중지되고, 검색은 10분 후 종료됩니다. 브라우저, 클립보드 또는 탐색기에서 온 링크는 절대 스스로 검색하지 않습니다.

라우터 자동 설정 (UPnP)이 추가되었으며, 필요한 수신 연결과 마찬가지로 기본적으로 꺼져 있습니다. 사설 네트워크의 기본 게이트웨이와만 통신하고, 한 번에 1시간 동안 유효한 전달 규칙 하나만 요청하며, 자신의 규칙만 제거합니다. macOS에서는 사용할 수 없다고 표시됩니다. 찾은 피어와 DHT 노드 중 다른 서비스의 포트(1024 미만 및 SIP 5060 등)를 쓰는 곳에는 절대 연결하지 않습니다. DHT 문제로 중지된 다운로드는 이제 선택한 언어로 이유를 표시합니다.

### Lua Provider API 1

Lua 다운로드 공급자로 소스 확인, 바이트 처리, 해시 검증 및 일반 일시 중지/재개를 사용할 수 있습니다. 각 다운로드는 저장된 스크립트 버전을 유지합니다. 로컬에서 생성한 암호화 파일로만 검증했습니다. 공급자를 저장하면 이전 앱 버전은 이 프로필에 쓸 수 없습니다.

## 3.4.1 — 2026-10-29

대규모 대기열에서 레코드 복사와 중복 검색을 줄였습니다. 작은 창에서는 파일 이름에 더 많은 공간을 제공합니다. 대기열 상태 옆에서 시작하거나 일시 중지할 수 있으며 시작은 예약을 재정의합니다. 상태에 마우스를 올리면 재시도 설명과 오류가 표시됩니다. 전송, 검증 및 이어받기 형식은 변경되지 않았습니다.

## 3.4.0 — 2026-10-29

### 테마 모음

환경설정 → 모양 → 사용자 지정에서 Neon Courier, Reactor Night, Aurora 및 Moonveil를 선택하세요. 배경 강도와 강조 색상을 조절하거나 PNG/JPEG를 가져올 수 있습니다. 저장하면 적용되고 취소하면 복원됩니다. 이미지는 크기 제한을 적용하여 백그라운드에서 처리하고 로컬에 저장합니다.

프로필 버전 보호와 MCP 접근 제어도 포함됩니다.

## 3.3.3 — 2026-10-28

### 인터페이스 개선

편집기와 불러온 스크립트를 별도 탭으로 분리했습니다. 스크립트 목록에서 검색하거나 새로 만들고, Lua 또는 PowerShell 편집기 헤더에서 전체 편집기를 열 수 있습니다. 저장, 실행/중지 및 선택적 로그를 코드와 함께 표시하며 파일 명령은 편집기 작업 메뉴로 옮겼습니다. 보기 전환 시 저장하지 않은 코드, 설정 및 커서 위치를 유지합니다.

### 더 빠르게 반응하는 다운로드 작업

대기열과 다운로드 상태 갱신, 브라우저 동영상 요청 및 다운로드 추가를 백그라운드에서 처리하여 느린 저장소가 클릭 처리를 막지 않도록 했습니다. 추가 중에는 진행 상태를 표시하고 중복 제출을 방지하며 저장에 실패하면 입력 내용을 유지합니다. 폴더 열기도 백그라운드에서 실행하며 이전 대기열 결과가 새 선택을 덮어쓰지 않습니다.
