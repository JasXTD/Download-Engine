### Download Engine 브라우저 식별자

브라우저 식별자를 Download Engine으로 변경했습니다. Firefox에서는 기존 개발용 확장 기능을 제거한 뒤 새 확장 기능을 설치하고 설정과 권한을 확인해야 합니다. 데스크톱 다운로드, 진행 상황과 대기열은 유지됩니다. 앱은 자체 연결을 이전하고 기존 확장 기능을 위한 별도의 호환 호스트를 유지합니다.
