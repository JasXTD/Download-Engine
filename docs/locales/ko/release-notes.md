## 3.0.2 — 2026-10-27

### 개인정보 처리방침

브라우저 연동, 로컬 저장소, 선택적 브라우저 로그인 쿠키, 데이터 보관 및 삭제, 외부 도구 연동과 Chrome 웹 스토어의 제한적 사용 요건을 설명하는 공개 개인정보 처리방침을 추가했습니다. README와 브라우저 출시 안내에 링크를 제공하며 소스, 확장 프로그램, 포터블 및 설치 패키지에도 사본을 포함합니다. 다운로드 동작과 권한은 변경되지 않았습니다.

### 소스 저장소 및 릴리스 패키지

FFmpeg 실행 파일은 더 이상 소스 저장소에서 추적하지 않습니다. 설치 프로그램과 포터블 릴리스에는 실행 파일, 해당 소스 코드 및 라이선스 고지가 계속 포함됩니다. FFmpeg 소스는 Git에 유지되며, 빌드 안내에서 일치하는 실행 파일을 구하는 방법을 설명합니다.
