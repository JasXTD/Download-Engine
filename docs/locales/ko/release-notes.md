## 3.1.1 — 2026-10-27

### 대용량 파일 완료 처리 개선

같은 드라이브에 있는 단일 부분 HTTP/HTTPS 및 FTP 다운로드는 저장된 파일을 검증한 후 그대로 저장하여 전체 복사본을 다시 쓰지 않습니다. 여러 부분은 기존의 비동기 처리로 순서대로 결합합니다. 다른 드라이브에 저장할 때는 안전하게 복사합니다. 체크섬 검증, 취소, 같은 이름의 파일 보호 및 인터넷 출처 표시를 유지합니다. 저장 중 중단되어도 저장된 부분이나 결합 파일에서 완료 상태를 복구하므로 다시 다운로드하거나 중복 파일을 만들지 않습니다.
