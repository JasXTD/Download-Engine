# Download Engine

## 시작하기

환경 설정은 범주별 팝업으로 열립니다. 저장하면 적용되고 취소, × 또는 Escape를 누르면 저장하지 않은 변경이 취소됩니다. 테마를 미리 볼 수 있으며 재설정은 현재 범주에만 적용됩니다. 고급 편집기는 별도로 저장하며 닫으면 환경 설정으로 돌아옵니다.

### 시작하기

도구 모음에서 URL 추가를 선택하고 직접 파일 링크를 붙여넣은 뒤 이름, 대기열, 저장 위치를 확인해 시작하세요. 일괄 추가는 한 줄에 링크 하나를 받습니다. 패턴으로를 선택하면 *가 하나 있는 링크로 img001…img100 같은 번호 링크를 만듭니다. 설정 → 화면 → 언어에서 변경할 수 있습니다. 시스템 언어는 Windows를 따르며 지원하지 않으면 영어를 사용합니다.

## 다운로드 및 복구

### 다운로드 및 복구

다운로드를 두 번 클릭하면 진행률, 속도, 남은 시간을 볼 수 있습니다. 일시 중지와 중지는 저장된 데이터를 유지합니다. 즉시 시작은 선택한 파일을 우선합니다. 이어받기에는 서버 지원과 동일 파일 확인이 필요합니다. 만료된 링크는 우클릭의 링크 갱신으로 복구하세요. 완료 항목 지우기는 기록만 제거하며 파일은 유지합니다. 작업 → 목록 내보내기…로 다운로드를 파일에 저장해 백업하거나 다른 PC로 옮길 수 있습니다. 작업 → 목록 가져오기…는 추가하기 전에 새 항목을 보여 주며, 이미 있는 링크는 건너뛰고 새 다운로드는 일시 중지 상태로 유지합니다. 보기 → 플로팅 드롭 상자를 켜면 다른 창 위에 항상 표시되는 작은 상자가 나타나며, Download Engine이 트레이에 있을 때도 링크를 끌어 놓아 다운로드할 수 있습니다.

## 오프라인 웹사이트

### 오프라인 웹사이트

수집기에서 다운로드 파일을 찾거나 웹사이트를 오프라인으로 저장하세요. 주소, 깊이, 페이지 및 크기 제한을 설정하고 결과를 검토합니다. 저장된 index.html을 열어 탐색합니다. 동적 기능, 로그인, 양식, 암호화 동영상은 지원하지 않습니다. 누락 항목은 보고서를 확인하세요.

## 브라우저 연동

### 브라우저 연동

도구 → 브라우저 설정에서 Chrome, Edge, Brave, Firefox를 연결합니다. Chrome, Edge, Brave는 설치된 확장 프로그램의 실제 ID가 필요합니다. 팝업의 연결 확인을 사용하세요. 브라우저 옵션에 별도 언어 선택기가 있습니다. 동영상 버튼은 화질 검토를 엽니다. 사이트 로그인은 명시적 승인 후 해당 다운로드에만 사용합니다.

## 대기열 및 일정

### 대기열 및 일정

대기열 관리에서 파일을 묶고 동시 다운로드 수를 설정하세요. 새 대기열은 시작하거나 예약할 때까지 대기합니다. 스케줄러에서 시작, 중지, 반복을 설정합니다. 앱은 트레이를 포함해 열려 있어야 합니다. 완료 후 앱 종료, 컴퓨터 종료, 절전, 최대 절전은 따로 켜며 카운트다운을 취소할 수 있습니다.

## 스크립트

### 스크립트

도구 → 스크립트에서 사이트나 확장자에 따른 규칙을 만드세요. 스크립트 탭에서 Lua 또는 PowerShell을 선택하고 저장한 뒤 실행합니다. 트리거는 수동, 앱 시작, 간격, 다운로드 완료, 대기열 완료입니다. 같은 스크립트는 겹쳐 실행되지 않습니다. 중지는 스크립트를 끝내지만 이미 보낸 다운로드 명령은 유지됩니다. 로그로 결과를 확인하세요.

## Lua 스크립팅

### Lua 스크립팅

Lua는 내장되어 있습니다. 새 스크립트에서 Lua와 수동 트리거를 선택하고 아래 예제를 저장해 실행하세요. xd.queues()는 대기열, xd.downloads()는 다운로드를 반환합니다. 완료 트리거는 event.downloads, 대기열 완료는 event.queue를 사용합니다. 명령과 필드 이름은 번역하지 않습니다. 자세한 내용은 docs/automation.md를 보세요. 로그에 비밀 정보를 출력하지 마세요. PowerShell은 Windows 계정 권한으로 실행됩니다.

Lua와 PowerShell 편집기는 입력이 잠시 멈추면 저장하거나 실행하지 않고 구문을 자동 검사합니다. 줄 번호, 구문 강조와 클릭하여 이동할 수 있는 오류 표시를 추가했습니다. 이름의 앞부분을 입력하거나 Ctrl+Space로 제안을 열고, 화살표로 선택한 뒤 Tab, Enter 또는 클릭으로 삽입합니다. Esc로 닫고 실행 취소도 사용할 수 있습니다. 실행 오류는 실행 로그에 표시됩니다.

```lua
print("Hello from Lua!")
print("Trigger:", event.trigger)
for _, queue in ipairs(xd.queues()) do
    print(queue.name, "running:", queue.running)
end
for _, file in ipairs(event.downloads) do
    print("Finished:", file.name or file.id)
end
```

다운로드 실패 트리거는 Download Engine 자체의 자동 재시도 후에도 다운로드에 확인이 필요할 때 스크립트를 실행합니다. 이때 event.downloads에는 각 다운로드의 error가 들어 있습니다. xd.retry(id)와 xd.restart(id)로 다시 시도하고(스크립트는 다운로드마다 최대 5번), xd.notify(title, text)로 Windows 알림을 표시하며, xd.store.get과 xd.store.set으로 실행 사이에 값을 보관합니다. xd.rename, xd.move, xd.remove는 다운로드한 파일 변경 허용이 켜져 있을 때만 파일을 바꿉니다. 샘플로 실행…은 선택한 다운로드로 이벤트 스크립트를 시험하며, 변경 사항은 시뮬레이션만 됩니다.

```lua
for _, file in ipairs(event.downloads) do
    if pcall(xd.retry, file.id) then
        print("Retrying:", file.name or file.id)
    else
        xd.notify("Download still failing", (file.name or file.id) .. ": " .. (file.error or "no details"))
    end
end
local handled = (xd.store.get("handled") or 0) + #event.downloads
xd.store.set("handled", handled)
print("Failed downloads handled:", handled)
```

다른 프로그램에서 스크립트를 편집하려면 편집기 머리글의 파일 열기…와 파일로 저장…을 사용하세요. 파일 열기…는 .lua 또는 .ps1 파일을 편집기에 복사하며, 저장되지 않은 코드를 바꾸게 되면 먼저 묻습니다. 유지하려면 스크립트 저장을 선택하세요. 파일로 저장…은 편집기의 코드를 파일로 씁니다.

## MCP 연동

### MCP 연동

MCP 페이지에서 로컬 HTTP 서버를 시작하고 클라이언트 설정을 복사하세요. 먼저 읽기 전용을 사용하세요. AI 클라이언트에는 URL과 비밀 인증 헤더가 필요합니다. 토큰을 공개하지 마세요. 서버 중지나 토큰 변경으로 접근을 취소할 수 있습니다. 자세한 내용은 docs/mcp-ai-guide.md에 있습니다.

이제 도구 모음, 도구 메뉴 또는 환경 설정에서 MCP 팝업을 열 수 있으며 현재 페이지는 유지됩니다. × 또는 Escape로 닫아도 서버는 계속 실행되고 저장하지 않은 MCP 편집 내용도 유지됩니다. AI 클라이언트 연결을 끊으려면 서버 중지를 사용하세요. 환경 설정에서 열었다면 닫을 때 같은 편집 내용으로 돌아갑니다.

## 바이러스 검사

스캐너: Microsoft Defender, Malwarebytes, Kaspersky, Bitdefender, ClamAV.

영문 백신 앱 탐색기 연동이 필요합니다. 시간 제한은 전달에만 적용됩니다. 검사는 백신 앱에서 취소하세요.

기본 설치 폴더가 필요합니다.

보호 및 격리는 백신 앱이 제어합니다. 요청 전송은 안전 판정이 아닙니다.

설정 확인: 연동을 찾았습니다. 스캔 요청 시 사용 가능 여부를 확인합니다.

### 바이러스 검사

도구 → 바이러스 검사를 여세요. 단일은 완료된 다운로드 하나를, 일괄은 여러 파일을 선택합니다. 단일 검사도 취소할 수 있습니다. 검사 중이거나 Malwarebytes / Kaspersky / Bitdefender 결과 검토를 기다리는 동안에는 탭이 잠깁니다.

설정에서 검사기를 선택하고 도구 → 바이러스 검사 → 일괄를 여세요. 완료된 파일을 선택해 시작하고 결과를 검토합니다. 중지는 미전송 요청을 취소합니다. Malwarebytes / Kaspersky / Bitdefender는 요청마다 사용자의 검토를 기다립니다. 이미 전달한 검사는 Malwarebytes / Kaspersky / Bitdefender에서 중지하세요. 요청됨은 안전 판정이 아닙니다.

## 설정 및 로그

### 설정 및 로그

설정에서 언어, 테마, 폴더, 속도, 데이터 한도, 프록시, 연결 수를 변경합니다. 로그에서 검색, 필터, 복사, 폴더 열기, 진단 내보내기를 사용할 수 있습니다. 실제 URL, 경로, 스크립트 출력, 기술 오류는 원문을 유지합니다. 공유 전에 보고서를 검토하세요.

설치 버전은 시작할 때마다 다른 드라이브로 이동한 위치를 포함해 Windows의 현재 다운로드 폴더를 확인합니다. 새 다운로드는 해당 위치를 사용하며 기존 다운로드, 저장된 진행 상황, 사용자 지정 폴더는 유지됩니다. 포터블 버전은 시작할 때마다 앱 위치를 기준으로 기본 폴더를 결정합니다. 이전 프로필은 IDM EX 하위 폴더 이름을 유지합니다. 위치를 확인할 수 없으면 오류를 표시합니다.

## 문제 해결

### 문제 해결

연결 실패 시 앱 실행 여부, 확장 프로그램 ID와 등록을 확인하세요. 업데이트 후 확장 프로그램과 페이지를 다시 불러오세요. 다운로드 실패 시 디스크 공간, 폴더 권한, 프록시, 링크 만료를 확인합니다. 이어받기 전에 복구 데이터를 삭제하지 마세요. 글자가 네모로 나오면 Windows 언어 글꼴을 추가하고 앱을 다시 시작하세요.
