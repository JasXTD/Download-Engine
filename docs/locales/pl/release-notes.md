## 3.0.0 — 2026-10-27

### Identyfikatory przeglądarki Download Engine

Identyfikatory przeglądarki używają teraz nazwy Download Engine. W Firefox usuń stare rozszerzenie deweloperskie przed instalacją nowego i sprawdź jego ustawienia oraz uprawnienia. Pobrane pliki, postęp i kolejki aplikacji pozostają bez zmian. Aplikacja przenosi własne połączenia i zachowuje oddzielnego hosta zgodności dla starszych rozszerzeń.

com.xetro.downloadengine · download-engine@xetro
