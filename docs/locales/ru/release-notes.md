## 3.8.0 — 2026-11-01

### Открытие торрентов из Windows

Открывайте файлы .torrent из Проводника и magnet-ссылки из браузера для проверки. Регистрация в Windows необязательна и не меняет приложения по умолчанию; ожидающие проверки сохраняются после перезапуска. Усилена защита торрентов: magnet без сохранённых метаданных требует трекер, иначе используйте файл .torrent. Добавлены регрессионные тесты существующей защиты от конфликтов имён файлов.

## 3.7.0 — 2026-11-01

### Загрузка торрентов

Добавлены торрент-файлы и magnet-ссылки с выбором файлов, паузой, продолжением и восстановлением проверенных данных. По умолчанию выключено; включение и управление отдачей доступны в настройках. При включении прокси торренты приостанавливаются, после завершения отдача прекращается. Включены исправления 3.6.1 и вспомогательный процесс торрентов.

### Подготовка выпуска

Обновлены руководство, README, сайт и проверки установщика. После добавления первого торрента профиль требует версии 3.7.0 или новее, чтобы старые версии не изменяли торрент-задания. Простое включение функции не обновляет профиль.

## 3.6.1 — 2026-10-31

### Сокращение зависимостей и подтверждение обновлений расширений

Вместо fs2 используются встроенные блокировки файлов Rust; старая зависимость winapi удалена. Поведение блокировок и ожидания сохранено. Обновления расширений, добавляющие задания, в том числе путём замены идентификатора задания, теперь требуют подтверждения даже для отключённого расширения.

## 3.6.0 — 2026-10-31

### Расширения

Новая страница «Расширения» заменяет «Скрипты» и содержит вкладки «Установлено», «Скрипты», «Правила» и «История запусков». Расширение — это один файл .de-extension.json, объединяющий обработчики сайтов, провайдеры загрузок и задания автоматизации. Установка возможна только из локального файла, издатели не проверяются. Окно проверки показывает, что может расширение, после установки оно выключено, а обновление должно запросить разрешение на новый доступ. Доступ к сети ограничен объявленными хостами. После установки первого расширения старые версии приложения не могут записывать этот профиль.

## 3.5.1 — 2026-10-29

### Безопасность поставщиков Lua

- Resolve/refresh и transform/finish выполняются в процессах с разными полномочиями. Обрабатывающий процесс не получает `xd.fetch` даже при загрузке исходного кода. Для инициализации по этапам используйте `xd.phase`; локальные переменные разрешения источника не передаются обработчику.
- Сохранённый план содержит только размер, хеши и идентификатор преобразования. Полученные URL обновляются по необходимости, а закреплённый за заданием код защищён DPAPI текущего пользователя Windows. Атомарное обновление старых заданий сохраняет привязки контрольных точек и блокирует запись старыми версиями.
- `xd.key` и команда `scripts protect-key`, читающая ключ из перенаправленного stdin, предоставляют непрозрачные дескрипторы ключей AES, привязанные к поставщику. Секретные ключи не нужно включать в код или экспорт. Старые резервные копии и ключи, записанные в существующих скриптах библиотеки, не удаляются; см. `docs/lua-providers.md`.

### Очистить историю

Перед очисткой истории завершённых загрузок появится подтверждение с очередью и количеством записей. Отмена или закрытие сохраняет историю. Скачанные файлы не удаляются.
