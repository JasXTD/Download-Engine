## 3.0.2 — 2026-10-27

### Политика конфиденциальности

Добавлена публичная политика, описывающая интеграцию с браузером, локальное хранение, необязательные файлы cookie для входа, хранение и удаление данных, сторонние интеграции и требования ограниченного использования Chrome Web Store. Ссылки доступны в README и руководстве по публикации расширений; копия включена в исходники, расширения, переносные пакеты и установщик. Работа загрузок и разрешения не изменились.

### Репозиторий исходного кода и пакеты выпуска

Исполняемый файл FFmpeg больше не отслеживается в репозитории исходного кода. Установщик и переносная версия по-прежнему включают его вместе с соответствующими исходниками и уведомлениями о лицензиях. Исходники FFmpeg остаются в Git; инструкции по сборке объясняют, как получить подходящий исполняемый файл.
