## 3.0.1 — 2026-10-27

### Значки расширений браузера

Расширения теперь содержат логотип Download Engine в размерах для панели инструментов и магазина. Пакеты Chrome, Edge, Brave и Firefox, установщик Windows и переносные версии включают одинаковые файлы значков.

### Инструкции по установке расширений

В README явно указано, что одобрение магазинов расширений ещё ожидается. Chrome, Edge и Brave требуют режима разработчика и загрузки распакованного расширения. В Firefox используется временное дополнение, которое нужно загружать заново после каждого перезапуска браузера. Раздел настройки содержит ссылки на инструкции по загрузке и подключению для каждого браузера.
