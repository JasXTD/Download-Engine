## 3.1.1 — 2026-10-27

### Более быстрое завершение больших файлов

Одночастные загрузки HTTP/HTTPS и FTP на одном диске теперь проверяются и сохраняются без записи второй полной копии. Части многопоточных загрузок сохраняют прежний асинхронный способ объединения по порядку. При сохранении на другой диск используется безопасное копирование. Сохранены проверка контрольной суммы, отмена, защита существующих имён и метка происхождения из Интернета. Прерванное сохранение восстанавливается из готовой части или объединяемого файла без повторной загрузки и дубликатов.
