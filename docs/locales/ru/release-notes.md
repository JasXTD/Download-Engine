## 3.15.0 — 2026-11-06

### Ядро провайдеров Lua и субтитры ASS

В HTTP API Lua добавлены HEAD, PUT, PATCH, DELETE и OPTIONS, двоичные тела с ограничением размера и явно передаваемые сеансы, привязанные к одному источнику. Учётные данные остаются зашифрованными вне модуля разрешения адресов, не сохраняются в планах и не передаются автономным обработчикам. Медиапланы поддерживают сегменты неизвестного размера; lua_stream обрабатывает ограниченные блоки со сверенными контрольными точками для паузы, продолжения, остановки и восстановления.

Добавлены импорт двоичных/RSA учётных данных с защитой ОС, случайные байты, SHA-1/SHA-256, HMAC, подпись и расшифровка RSA, а также расшифровка блоков AES. Субтитры ASS сохраняют стили и встроенные переопределения в MKV, а в MP4 преобразуются в текстовые субтитры. Новые функции учётных данных и мультимедиа требуют приложения с поддержкой версии записи профиля 9; прежние форматы контрольных точек остаются совместимыми.

Автономная лаборатория CENC для авторов использует Lua для разбора ограниченного подмножества шифрования сэмплов AVC/AAC, имитации обмена подписанной лицензией, передачи ключей и объединения расшифрованных дорожек с субтитрами ASS. Аутентификацию сайтов, форматы лицензий и разбор контейнеров по-прежнему реализует код Lua. Проверки используют сгенерированные данные без реальных сервисов и аккаунтов; это не полная реализация CENC.

### Раздача и поиск торрентов

Раздача завершённого торрента теперь сама останавливается при рейтинге 2.0 или через неделю — смотря что наступит раньше. Это включено по умолчанию, в том числе для существующих профилей; оба ограничения можно изменить или отключить в разделе Параметры → Торренты. Отдача во время загрузки тоже учитывается в рейтинге. Окно состояния показывает рейтинг, а торрент, остановленный по ограничению, сохраняет файлы и предлагает в меню пункт Раздавать снова.

Магнитные ссылки без трекера больше не отклоняются сразу. Окно Добавить загрузку объясняет, что при поиске в DHT другие компьютеры увидят, какой торрент вы ищете, и ваш IP-адрес, и начинает поиск только после нажатия Искать в DHT. Ваш компьютер объявляется как пир только после того, как проверенный список файлов подтвердит, что торрент публичный. Закрытый торрент останавливает поиск, а сам поиск завершается через 10 минут. Ссылки из браузеров, буфера обмена или Проводника никогда не запускают поиск сами.

Новая функция Настраивать маршрутизатор (UPnP) по умолчанию отключена, как и нужные ей входящие подключения. Она обращается только к основному шлюзу частной сети, запрашивает одно правило переадресации сроком на час с продлением, пока работают торренты, и удаляет только своё правило; в macOS она недоступна. К найденным пирам и узлам DHT на портах других служб (ниже 1024, а также, например, SIP 5060) приложение никогда не подключается. Загрузки, остановленные по причине DHT, теперь показывают причину на выбранном языке.

## 3.5.1 — 2026-10-29

### Безопасность поставщиков Lua

- Resolve/refresh и transform/finish выполняются в процессах с разными полномочиями. Обрабатывающий процесс не получает `xd.fetch` даже при загрузке исходного кода. Для инициализации по этапам используйте `xd.phase`; локальные переменные разрешения источника не передаются обработчику.
- Сохранённый план содержит только размер, хеши и идентификатор преобразования. Полученные URL обновляются по необходимости, а закреплённый за заданием код защищён DPAPI текущего пользователя Windows. Атомарное обновление старых заданий сохраняет привязки контрольных точек и блокирует запись старыми версиями.
- `xd.key` и команда `scripts protect-key`, читающая ключ из перенаправленного stdin, предоставляют непрозрачные дескрипторы ключей AES, привязанные к поставщику. Секретные ключи не нужно включать в код или экспорт. Старые резервные копии и ключи, записанные в существующих скриптах библиотеки, не удаляются; см. `docs/lua-providers.md`.
