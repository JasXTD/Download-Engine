# Download Engine

## Начало работы

Параметры открываются в окне с категориями. Сохранить применяет изменения; Отмена, × или Escape отменяет несохранённые правки. Тема доступна для предпросмотра; сброс относится только к текущей категории. Расширенные редакторы сохраняют отдельно и после закрытия возвращают в Параметры.

### Начало работы

Выберите «Добавить URL», вставьте прямую ссылку, проверьте имя, очередь и папку, затем начните загрузку. Пакет принимает по одной ссылке на строку. «По шаблону» создаёт нумерованные ссылки вроде img001…img100 из одной ссылки со *. Язык меняется в Настройки → Внешний вид → Язык. Системный язык следует Windows; неподдерживаемый заменяется английским.

## Загрузки и восстановление

### Загрузки и восстановление

Двойной щелчок по загрузке открывает прогресс, скорость и оставшееся время. Пауза и остановка сохраняют данные. Немедленный запуск даёт приоритет выбранным файлам. Продолжение требует поддержки сервера и проверки совпадения файла. Истёкшую ссылку обновите через контекстное меню. Очистка завершённых удаляет только историю, сохраняя файлы. Задачи → Экспорт списка… сохраняет загрузки в файл для резервной копии или переноса на другой ПК. Задачи → Импорт списка… перед добавлением показывает новые элементы; уже имеющиеся ссылки пропускаются, а новые загрузки остаются приостановленными. Вид → Плавающее окно перетаскивания показывает небольшое окно поверх других окон; перетащите на него ссылки, чтобы скачать их, даже когда Download Engine свёрнут в трей.

## Сайты офлайн

### Сайты офлайн

Сборщик ищет файлы или сохраняет сайт офлайн. Задайте URL, глубину, лимиты страниц и размера, затем просмотрите результат. Откройте сохранённый index.html. Динамические функции, вход, формы и зашифрованное видео не поддерживаются. Пропуски указаны в отчёте.

## Интеграция с браузером

### Интеграция с браузером

Откройте Инструменты → Настройка браузера для Chrome, Edge, Brave или Firefox. Chrome, Edge и Brave требуют настоящий ID установленного расширения. Проверьте соединение в его окне. Параметры браузера содержат отдельный выбор языка. Видеокнопка открывает выбор качества. Вход сайта используется только для этого файла после вашего разрешения.

## Очереди и расписания

### Очереди и расписания

Управление очередями группирует файлы и задаёт число одновременных загрузок. Новые очереди ждут запуска или расписания. Планировщик поддерживает начало, остановку и повторение. Приложение должно работать, включая трей. Выход, выключение, сон и гибернация компьютера включаются отдельно; обратный отсчёт можно отменить.

## Скрипты

Редактор и загруженные скрипты теперь находятся на отдельных вкладках. Поиск и создание скриптов доступны в списке, а полный редактор открывается из заголовка Lua или PowerShell. Сохранение, запуск/остановка и необязательные журналы расположены рядом с кодом. Файловые команды перенесены в меню действий редактора. Смена вида сохраняет несохранённый код, настройки и положение курсора.


### Скрипты

В Инструменты → Скрипты создайте правила по сайту или расширению файла. В скриптах выберите Lua или PowerShell, сохраните и запустите. Триггеры: вручную, запуск приложения, интервал, завершение загрузки и очереди. Скрипт не запускается поверх себя. Остановка завершает скрипт, но не отменяет уже отправленные команды загрузки. Результат смотрите в журнале.

## Скрипты Lua

### Скрипты Lua

Lua встроен. Создайте Lua-скрипт с ручным триггером, сохраните и запустите пример ниже. xd.queues() возвращает очереди, xd.downloads() — загрузки. Завершение загрузки даёт event.downloads, очереди — event.queue. Имена команд и полей не переводятся. Полный API: docs/automation.md. Не печатайте секреты в журналах. PowerShell работает с правами вашей учётной записи Windows.

Редакторы Lua и PowerShell автоматически проверяют синтаксис после короткой паузы ввода, не сохраняя и не запуская скрипт. Добавлены номера строк, подсветка синтаксиса и переход к ошибке по нажатию. Введите начало имени или нажмите Ctrl+Space, выберите подсказку стрелками и вставьте через Tab, Enter или щелчок. Esc закрывает подсказки. Поддерживается отмена; ошибки выполнения остаются в журнале.

```lua
print("Hello from Lua!")
print("Trigger:", event.trigger)
for _, queue in ipairs(xd.queues()) do
    print(queue.name, "running:", queue.running)
end
for _, file in ipairs(event.downloads) do
    print("Finished:", file.name or file.id)
end
```

Триггер «Ошибка загрузки» запускает скрипт, когда загрузка всё ещё требует внимания после автоматических повторов Download Engine; тогда event.downloads содержит error каждой загрузки. xd.retry(id) и xd.restart(id) повторяют попытку (скрипт может сделать это 5 раз для одной загрузки), xd.notify(title, text) показывает уведомление Windows, а xd.store.get и xd.store.set сохраняют значения между запусками. xd.rename, xd.move и xd.remove меняют файл, только если включено «Может изменять скачанные файлы». «Запустить с примером…» проверяет скрипт события на выбранных загрузках; изменения только имитируются.

```lua
for _, file in ipairs(event.downloads) do
    if pcall(xd.retry, file.id) then
        print("Retrying:", file.name or file.id)
    else
        xd.notify("Download still failing", (file.name or file.id) .. ": " .. (file.error or "no details"))
    end
end
local handled = (xd.store.get("handled") or 0) + #event.downloads
xd.store.set("handled", handled)
print("Failed downloads handled:", handled)
```

Чтобы редактировать скрипт в другой программе, используйте «Открыть файл…» и «Сохранить в файл…» в заголовке редактора. «Открыть файл…» копирует файл .lua или .ps1 в редактор и сначала спрашивает, если при этом заменится несохранённый код; выберите «Сохранить скрипт», чтобы сохранить его. «Сохранить в файл…» записывает код из редактора в файл.

### Lua Core API 1

Создайте или откройте скрипт в Loaded scripts; выберите Lua и Manual only в Script settings. Full editor увеличивает редактор; нажмите Save script, затем Run script и проверьте Run logs. Core API показывает функции текущего триггера, Ctrl+Space — подсказки. API 1 — версия контракта, а не приложения. Пример разбирает HTML только в памяти, без сети и загрузок; доступность чтения страниц для ручного скрипта — false.

```lua
-- Example: core-api
assert(xd.api_version == 1, "This example needs Lua API 1")
print("App:", xd.app_version, "Role:", xd.script_kind)
local html = '<a class="download" href="/files/demo.zip">Demo</a>'
local links = xd.html_select(html, "a.download[href]", "href")
local url = xd.url_join("https://example.com/catalog/", links[1])
print("Preview:", xd.to_json({ kind = "file", url = url }))
print("Can fetch a page:", xd.supports("xd.fetch"))
```

Open examples/core-api-automation.lua or examples/custom-site-reader.lua with Editor actions → Open file…. Site reader uses public pages, Pages patterns and Direct connection; test with Test on URL before enabling its trigger. Ordinary automation cannot call xd.fetch. Import script… accepts .de-script.json as a new draft with automatic triggers and file changes off; review its code and reselect local queues. Stop script does not undo submitted downloads. Full English reference: docs/automation.md.

## Интеграция MCP

### Интеграция MCP

На странице MCP запустите локальный HTTP-сервер и скопируйте настройки клиента. Начните с режима просмотра. ИИ нужны URL и секретный заголовок авторизации. Не публикуйте токен. Остановите сервер или смените токен, чтобы отозвать доступ. Подробности: docs/mcp-ai-guide.md.

MCP теперь открывается во всплывающем окне с панели инструментов, из меню «Инструменты» или настроек, сохраняя текущую страницу. Закрытие через × или Escape не останавливает сервер и сохраняет несохранённые изменения MCP. Для отключения клиентов ИИ остановите сервер. При открытии из настроек закрытие возвращает к тому же черновику.

## Антивирусная проверка

Сканер: Microsoft Defender, Malwarebytes, Kaspersky, Bitdefender, ClamAV.

Нужна английская интеграция антивирусе с Проводником. Тайм-аут ограничивает передачу, не проверку. Отменяйте проверку в антивирусе.

Требуется стандартная папка установки.

Защитой и карантином управляет антивирус. Запрос не означает отсутствия угроз.

Проверить настройку: Интеграция найдена; доступность сканирования проверяется при запросе.

### Антивирусная проверка

Откройте Инструменты → Проверка антивирусом. «Один файл» позволяет выбрать одну завершённую загрузку, «Пакет» — несколько. Одиночную проверку можно отменить. Вкладки заблокированы во время проверки и ожидания просмотра результатов Malwarebytes / Kaspersky / Bitdefender.

Выберите антивирус в настройках, затем Инструменты → Проверка антивирусом → Пакет. Выберите готовые файлы, запустите и просмотрите результаты. Остановка отменяет неотправленные запросы. Malwarebytes / Kaspersky / Bitdefender ждёт вашей проверки после каждого запроса. Уже переданные проверки останавливайте в Malwarebytes / Kaspersky / Bitdefender. Отправленный запрос не означает безопасность файла.

## Настройки и журналы

### Настройки и журналы

Настройки включают язык, тему, папки, скорость, квоты, прокси и число соединений. Журналы можно искать, фильтровать, копировать и экспортировать. URL, пути, вывод скриптов и технические ошибки сохраняют исходный текст. Проверяйте отчёт перед отправкой другим.

Установленная версия при каждом запуске запрашивает текущую папку загрузок Windows, в том числе перенесённую на другой диск. Новые загрузки используют это расположение. Существующие загрузки, сохранённый прогресс и выбранные папки не меняются. Переносная версия каждый раз определяет папку относительно приложения. Старые профили сохраняют имя подпапки IDM EX. Если расположение определить не удалось, отображается ошибка.

## Устранение неполадок

### Устранение неполадок

При ошибке соединения проверьте запуск приложения, ID расширения и регистрацию. После обновления перезагрузите расширение и страницу. При ошибке загрузки проверьте диск, права папки, прокси и срок ссылки. Не удаляйте данные восстановления до попытки продолжения. Если вместо букв квадраты, добавьте языковые шрифты Windows и перезапустите приложение.
