## 3.15.0 — 2026-11-06

### แกนหลักของผู้ให้บริการ Lua และคำบรรยาย ASS

HTTP ใน Lua เพิ่ม HEAD, PUT, PATCH, DELETE และ OPTIONS เนื้อหาไบนารีที่จำกัดขนาด และเซสชันที่ส่งให้อย่างชัดเจนโดยผูกกับต้นทางเดียว ข้อมูลรับรองยังคงเข้ารหัสเมื่ออยู่นอกตัวแก้ไขแหล่งข้อมูล และไม่ถูกบันทึกในแผนหรือส่งให้ตัวประมวลผลออฟไลน์ แผนสื่อรองรับส่วนที่ยังไม่ทราบขนาด ส่วน lua_stream ประมวลผลข้อมูลเป็นชิ้นที่มีขอบเขต พร้อมจุดตรวจสอบที่ยืนยันแล้วสำหรับการพัก ทำต่อ หยุด และกู้คืน

เพิ่มการนำเข้าข้อมูลรับรองไบนารี/RSA ที่ระบบปฏิบัติการปกป้อง ไบต์สุ่ม SHA-1/SHA-256, HMAC การลงลายมือชื่อและถอดรหัส RSA รวมถึงการถอดรหัสบล็อก AES คำบรรยาย ASS คงรูปแบบและคำสั่งปรับรูปแบบในบรรทัดไว้ใน MKV แต่แปลงเป็นคำบรรยายข้อความใน MP4 ฟีเจอร์ข้อมูลรับรองและสื่อใหม่ต้องใช้แอปที่รองรับรุ่นการเขียนโปรไฟล์ 9 รูปแบบจุดตรวจสอบเดิมยังเข้ากันได้

ห้องทดลอง CENC แบบออฟไลน์สำหรับผู้เขียนใช้ Lua วิเคราะห์รูปแบบการเข้ารหัสตัวอย่าง AVC/AAC บางส่วน สาธิตการแลกเปลี่ยนใบอนุญาตจำลองที่ลงลายมือชื่อ การส่งต่อกุญแจ และการรวมแทร็กที่ถอดรหัสแล้วกับคำบรรยาย ASS การยืนยันตัวตนกับเว็บไซต์ รูปแบบใบอนุญาต และตัวแยกวิเคราะห์คอนเทนเนอร์ยังต้องเขียนด้วย Lua การทดสอบใช้ข้อมูลที่สร้างขึ้น ไม่ใช้บริการหรือบัญชีจริง และนี่ไม่ใช่การรองรับ CENC อย่างสมบูรณ์

### การแชร์และค้นหาทอร์เรนต์

การแชร์ทอร์เรนต์ที่ดาวน์โหลดเสร็จแล้วจะหยุดเองเมื่ออัตราส่วนถึง 2.0 หรือครบหนึ่งสัปดาห์ แล้วแต่ว่าอย่างใดถึงก่อน ตัวเลือกนี้เปิดไว้โดยค่าเริ่มต้น รวมถึงในโปรไฟล์ที่มีอยู่เดิม และเปลี่ยนหรือปิดขีดจำกัดทั้งสองได้ในการตั้งค่า → ทอร์เรนต์ การอัปโหลดระหว่างดาวน์โหลดก็นับรวมในอัตราส่วนด้วย หน้าต่างสถานะแสดงอัตราส่วน และทอร์เรนต์ที่หยุดเพราะถึงขีดจำกัดจะยังเก็บไฟล์ไว้และมีคำสั่งแชร์อีกครั้งในเมนู

ลิงก์ magnet ที่ไม่มีแทร็กเกอร์จะไม่ถูกปฏิเสธทันทีอีกต่อไป หน้าต่างเพิ่มการดาวน์โหลดจะอธิบายว่าการค้นหาใน DHT ทำให้คอมพิวเตอร์เครื่องอื่นเห็นว่าคุณต้องการทอร์เรนต์ใดและเห็นที่อยู่ IP ของคุณ และจะค้นหาหลังจากคุณคลิกค้นหาใน DHT เท่านั้น คอมพิวเตอร์ของคุณจะถูกประกาศเป็นเพียร์ก็ต่อเมื่อรายการไฟล์ที่ตรวจสอบแล้วยืนยันว่าเป็นทอร์เรนต์สาธารณะ ทอร์เรนต์ส่วนตัวจะทำให้การค้นหาหยุดลง และการค้นหาจะสิ้นสุดหลัง 10 นาที ลิงก์จากเบราว์เซอร์ คลิปบอร์ด หรือ Explorer จะไม่เริ่มค้นหาเองเลย

เพิ่มตัวเลือกตั้งค่าเราเตอร์ให้อัตโนมัติ (UPnP) ซึ่งปิดไว้โดยค่าเริ่มต้นเช่นเดียวกับการเชื่อมต่อขาเข้าที่ตัวเลือกนี้ต้องใช้ ตัวเลือกนี้ติดต่อเฉพาะเกตเวย์เริ่มต้นในเครือข่ายส่วนตัว ขอกฎส่งต่อพอร์ตเพียงกฎเดียวที่มีอายุครั้งละหนึ่งชั่วโมง และลบเฉพาะกฎของตัวเอง บน macOS จะแสดงว่าใช้งานไม่ได้ เพียร์และโหนด DHT ที่พบซึ่งใช้พอร์ตของบริการอื่น (ต่ำกว่า 1024 และพอร์ตอย่าง SIP 5060) จะไม่ถูกติดต่อเลย ดาวน์โหลดที่หยุดด้วยสาเหตุเกี่ยวกับ DHT จะแสดงสาเหตุเป็นภาษาที่เลือกแล้ว

อัปเดตคู่มือ README เว็บไซต์ และการตรวจสอบตัวติดตั้งแล้ว หลังเพิ่มทอร์เรนต์แรก โปรไฟล์จะต้องใช้รุ่น 3.7.0 ขึ้นไป เพื่อป้องกันรุ่นเก่าแก้ไขงานทอร์เรนต์ การเปิดใช้คุณสมบัติเพียงอย่างเดียวจะไม่อัปเกรดโปรไฟล์

## 3.6.1 — 2026-10-31

### ลดไลบรารีที่พึ่งพาและการอนุมัติส่วนขยาย

เปลี่ยนจาก fs2 มาใช้การล็อกไฟล์ในตัวของ Rust และนำ winapi รุ่นเก่าออก โดยคงพฤติกรรมการล็อกและการรอเดิมไว้ การอัปเดตส่วนขยายที่เพิ่มงาน รวมถึงการเปลี่ยน ID ของงาน ต้องได้รับอนุมัติแม้ส่วนขยายจะปิดอยู่

## 3.6.0 — 2026-10-31

### ส่วนขยาย

หน้าส่วนขยายใหม่แทนที่หน้าสคริปต์ โดยมีแท็บติดตั้งแล้ว สคริปต์ กฎ และประวัติการทำงาน ส่วนขยายคือไฟล์ .de-extension.json ไฟล์เดียวที่รวมตัวอ่านเว็บไซต์ ผู้ให้บริการดาวน์โหลด และงานอัตโนมัติ ติดตั้งได้จากไฟล์ในเครื่องเท่านั้น และยังไม่ได้ยืนยันผู้เผยแพร่ หน้าตรวจสอบจะแสดงสิ่งที่ส่วนขยายทำได้ เมื่อติดตั้งแล้วจะปิดอยู่ และการอัปเดตต้องขออนุญาตก่อนรับสิทธิ์ใหม่ การเข้าถึงเว็บจำกัดเฉพาะโฮสต์ที่ประกาศไว้ เมื่อติดตั้งส่วนขยายแรกแล้ว แอปรุ่นเก่าจะเขียนโปรไฟล์นี้ไม่ได้

## 3.5.2 — 2026-10-30

### ตรวจหาการอัปเดตเมื่อเปิดแอป

เปิดใช้งานโดยค่าเริ่มต้นและตรวจสอบหนึ่งครั้งทุกครั้งที่เปิดแอป เมื่อพบรุ่นใหม่ คุณเลือกรับการอัปเดตหรือทำภายหลังได้ ข้อผิดพลาดขณะออฟไลน์จะไม่เปิดกล่องโต้ตอบ และปิดตัวเลือกนี้ได้ในการตั้งค่า ดาวน์โหลดและติดตั้งการอัปเดตจากหน้าเผยแพร่ GitHub อย่างเป็นทางการ

## 3.5.1 — 2026-10-29

### ความปลอดภัยของผู้ให้บริการ Lua

- resolve/refresh และ transform/finish ทำงานในโปรเซสที่แยกสิทธิ์กัน โปรเซสประมวลผลไม่มี `xd.fetch` แม้ขณะโหลดซอร์ส ใช้ `xd.phase` เพื่อเริ่มต้นตามเฟส ตัวแปรภายในของเฟสแก้ไขแหล่งข้อมูลจะไม่ถูกส่งต่อไปยังเฟสประมวลผล
- แผนที่บันทึกเก็บเฉพาะขนาด แฮช และตัวระบุการแปลง URL ที่ได้จะรีเฟรชเมื่อต้องใช้ ส่วนซอร์สที่ตรึงไว้กับงานได้รับการป้องกันด้วย DPAPI ของผู้ใช้ Windows ปัจจุบัน งานเดิมจะอัปเกรดแบบอะตอมมิกโดยคงการเชื่อมโยงจุดตรวจสอบและปิดกั้นการเขียนจากรุ่นเก่า
- `xd.key` และ `scripts protect-key` ซึ่งอ่านคีย์จาก stdin ที่เปลี่ยนเส้นทาง ให้แฮนเดิลคีย์ AES ที่ไม่เปิดเผยคีย์และผูกกับผู้ให้บริการ จึงไม่ต้องใส่คีย์ลับในซอร์สหรือไฟล์ส่งออก แต่จะไม่ลบข้อมูลสำรองเก่าหรือคีย์ที่เขียนไว้ในสคริปต์เดิมของคลัง ดู `docs/lua-providers.md`

### ล้างประวัติ

การล้างประวัติที่เสร็จแล้วจะแสดงหน้าต่างยืนยัน พร้อมคิวและจำนวนรายการ ยกเลิกหรือปิดหน้าต่างเพื่อเก็บประวัติไว้ ไฟล์ที่ดาวน์โหลดจะไม่ถูกลบ

## 3.3.3 — 2026-10-28

### ปรับปรุงส่วนติดต่อ

ตัวแก้ไขและรายการสคริปต์ที่โหลดมีแท็บแยกกันแล้ว ค้นหาหรือสร้างสคริปต์ในรายการ และเปิดตัวแก้ไขแบบเต็มจากส่วนหัว Lua หรือ PowerShell ปุ่มบันทึก เรียกใช้/หยุด และบันทึกการทำงานแบบเลือกแสดงอยู่ร่วมกับโค้ด คำสั่งไฟล์อยู่ในเมนูการทำงานของตัวแก้ไข การสลับมุมมองจะเก็บโค้ดที่ยังไม่บันทึก การตั้งค่า และตำแหน่งเคอร์เซอร์ไว้

### การดาวน์โหลดตอบสนองได้ดีขึ้น

การอัปเดตคิวและสถานะ คำขอวิดีโอจากเบราว์เซอร์ และการเพิ่มรายการดาวน์โหลดทำงานเบื้องหลัง เพื่อไม่ให้พื้นที่จัดเก็บที่ช้าขัดขวางการคลิก กล่องโต้ตอบแสดงความคืบหน้า ป้องกันการส่งซ้ำ และเก็บข้อมูลที่กรอกไว้หากบันทึกไม่สำเร็จ การเปิดโฟลเดอร์ทำงานเบื้องหลังเช่นกัน และผลการอัปเดตคิวเก่าจะไม่แทนที่คิวที่เพิ่งเลือก
