## 3.0.2 — 2026-10-27

### นโยบายความเป็นส่วนตัว

เพิ่มนโยบายสาธารณะเกี่ยวกับการเชื่อมต่อเบราว์เซอร์ การเก็บข้อมูลในเครื่อง คุกกี้เข้าสู่ระบบที่ผู้ใช้เลือกอนุญาต การเก็บรักษาและลบข้อมูล การเชื่อมต่อเครื่องมือภายนอก และข้อกำหนดการใช้งานแบบจำกัดของ Chrome Web Store README และคู่มือเผยแพร่ส่วนขยายมีลิงก์ไปยังนโยบาย และแพ็กเกจซอร์สโค้ด ส่วนขยาย รุ่นพกพา และตัวติดตั้งมีสำเนานโยบาย พฤติกรรมการดาวน์โหลดและสิทธิ์ไม่เปลี่ยนแปลง

### คลังซอร์สโค้ดและแพ็กเกจรุ่นเผยแพร่

ไฟล์ปฏิบัติการ FFmpeg ไม่ได้อยู่ภายใต้การติดตามของคลังซอร์สโค้ดอีกต่อไป ตัวติดตั้งและรุ่นพกพายังคงรวมไฟล์นี้พร้อมซอร์สโค้ดที่ตรงกันและประกาศสิทธิ์การใช้งาน ซอร์สโค้ด FFmpeg ยังคงอยู่ใน Git และคู่มือการสร้างโปรแกรมอธิบายวิธีรับไฟล์ปฏิบัติการที่ตรงกัน
