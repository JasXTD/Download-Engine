## 3.0.1 — 2026-10-27

### ไอคอนส่วนขยายเบราว์เซอร์

ส่วนขยายเบราว์เซอร์มีโลโก้ Download Engine ในขนาดสำหรับแถบเครื่องมือและร้านค้าแล้ว แพ็กเกจ Chrome, Edge, Brave และ Firefox รวมถึงตัวติดตั้ง Windows และรุ่นพกพามีไฟล์ไอคอนชุดเดียวกัน

### คู่มือการติดตั้งส่วนขยายเบราว์เซอร์

README ระบุชัดเจนแล้วว่ายังรอการอนุมัติจากร้านค้าส่วนขยาย Chrome, Edge และ Brave ต้องเปิดโหมดนักพัฒนาและโหลดส่วนขยายที่แตกไฟล์แล้ว ส่วน Firefox ใช้ส่วนเสริมชั่วคราวและต้องโหลดใหม่ทุกครั้งที่เริ่มเบราว์เซอร์ใหม่ หัวข้อการตั้งค่ามีลิงก์ไปยังขั้นตอนการโหลดและเชื่อมต่อสำหรับแต่ละเบราว์เซอร์
