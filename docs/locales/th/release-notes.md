## 3.1.1 — 2026-10-27

### ทำขั้นตอนสุดท้ายของไฟล์ขนาดใหญ่ได้เร็วขึ้น

การดาวน์โหลด HTTP/HTTPS และ FTP แบบส่วนเดียวบนไดรฟ์เดียวกันจะตรวจสอบและบันทึกไฟล์ที่ดาวน์โหลดไว้โดยไม่เขียนสำเนาทั้งไฟล์อีกครั้ง ไฟล์หลายส่วนยังคงรวมตามลำดับด้วยกระบวนการแบบอะซิงโครนัสเดิม ส่วนการบันทึกข้ามไดรฟ์ยังคงใช้การคัดลอกที่ปลอดภัย การตรวจสอบเช็กซัม การยกเลิก การป้องกันชื่อไฟล์ซ้ำ และเครื่องหมายแหล่งที่มาจากอินเทอร์เน็ตยังคงทำงาน หากขั้นตอนบันทึกถูกขัดจังหวะ จะกู้คืนจากส่วนที่บันทึกไว้หรือไฟล์ที่รวมแล้วโดยไม่ดาวน์โหลดใหม่หรือสร้างไฟล์ซ้ำ
