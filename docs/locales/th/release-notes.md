## 3.2.0 — 2026-10-28

### ลิงก์สาธารณะ

เพิ่มการรองรับไฟล์เดี่ยวสาธารณะของ MEGA และการโอนสาธารณะของ WeTransfer โดย MEGA จะถอดรหัสในเครื่องและตรวจสอบความสมบูรณ์ การหยุดชั่วคราวและดาวน์โหลดต่ออย่างปลอดภัยขึ้นอยู่กับเซิร์ฟเวอร์และข้อมูลระบุตัวไฟล์

ไม่รองรับการโอนที่มีรหัสผ่าน ต้องใช้บัญชี หมดอายุ หรือโฟลเดอร์ MEGA

### การค้นหาไฟล์และการเชื่อมต่อเบราว์เซอร์

โปรแกรมค้นหาลิงก์ไฟล์ในหน้าดาวน์โหลดได้ และขอให้ตรวจสอบตัวเลือกที่ไม่ชัดเจนหรือลิงก์ข้ามเว็บไซต์ ส่วนขยายจะเก็บคีย์ MEGA และรองรับการดาวน์โหลดไฟล์ต้นฉบับจาก GitHub โปรดโหลดส่วนขยายใหม่หลังอัปเกรด

### เว็บไซต์และเอกสาร

เว็บไซต์เพิ่มข้อมูลการรองรับวิดีโอ ตัวอย่าง Web Grabber รายละเอียดบริการแชร์ไฟล์ และภาพหน้าจอแบบสไลด์

ตัวติดตั้งและรุ่นพกพายังคงรวม FFmpeg ซอร์สโค้ดที่ตรงกัน และใบอนุญาต

เพิ่มการตรวจสอบรุ่นเสถียรบน GitHub ด้วยตนเอง การลองใหม่ และลิงก์หน้ารุ่นเผยแพร่ในเมนูช่วยเหลือ หน้าเกี่ยวกับเชื่อมโยงไปยังคลัง GitHub ทางการ
