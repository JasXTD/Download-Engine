## 3.0.0 — 2026-10-27

### ตัวระบุเบราว์เซอร์ Download Engine

ตัวระบุเบราว์เซอร์เปลี่ยนเป็นชื่อ Download Engine แล้ว สำหรับ Firefox ให้ลบส่วนขยายสำหรับนักพัฒนาเดิมก่อนติดตั้งส่วนขยายใหม่ แล้วตรวจสอบการตั้งค่าและสิทธิ์อีกครั้ง การดาวน์โหลด ความคืบหน้า และคิวในแอปเดสก์ท็อปยังคงเดิม แอปจะย้ายการเชื่อมต่อของตนเองและคงโฮสต์สำหรับความเข้ากันได้แยกไว้ให้ส่วนขยายเก่า

com.xetro.downloadengine · download-engine@xetro

### กฎหมายและใบอนุญาตในหน้าเกี่ยวกับ

หน้าเกี่ยวกับมีตัวอ่านแบบออฟไลน์สำหรับใบอนุญาต MIT ของแอปและประกาศของบุคคลที่สามที่มาพร้อมแอปแล้ว สามารถอ่านและคัดลอกข้อความต้นฉบับ สลับเอกสาร และกลับไปที่หน้าเกี่ยวกับโดยไม่เปลี่ยนแปลงการดาวน์โหลด ปุ่มควบคุมใช้ภาษาหน้าจอที่เลือกและรองรับทั้งสองธีม
