## 3.1.0 — 2026-10-27

### ดาวน์โหลดวิดีโอเร็วขึ้นและลดภาระการถ่ายโอน

วิดีโอดาวน์โหลดพร้อมกันได้สูงสุด 4 ส่วน และปฏิบัติตามขีดจำกัดการเชื่อมต่อส่วนกลางหรือรายเว็บไซต์ที่ต่ำกว่า การหยุดชั่วคราว ลองใหม่ และเปิดแอปใหม่จะเก็บส่วนที่เสร็จและตรวจสอบแล้ว แม้เสร็จไม่ตามลำดับ ส่วนที่ยังไม่เสร็จจะดาวน์โหลดใหม่ หน้าต่างสถานะแสดงส่วนและการเชื่อมต่อที่ใช้งานอยู่ ลดภาระด้วยบัฟเฟอร์การเขียนดิสก์ ลดความถี่การอัปเดตความคืบหน้า และใช้การเชื่อมต่อฐานข้อมูลซ้ำ การหยุดชั่วคราวยังรอให้เขียนเสร็จและยังบันทึกโควตาอย่างถาวรทุกก้อนข้อมูลที่รับ

### สถานะข้อผิดพลาดที่ชัดเจนขึ้น

เปลี่ยนป้ายสถานะข้อผิดพลาดเป็น “ล้มเหลว” โดยคงรายละเอียดและการลองใหม่อัตโนมัติไว้
