## ดาวน์โหลดและการกู้คืน

### ดาวน์โหลดและการกู้คืน

ดับเบิลคลิกรายการดาวน์โหลดเพื่อดูความคืบหน้า ความเร็ว และเวลาที่เหลือ หยุดชั่วคราวและหยุดจะเก็บข้อมูลไว้ เริ่มทันทีให้ความสำคัญกับไฟล์ที่เลือก การทำต่อต้องมีการรองรับจากเซิร์ฟเวอร์และตรวจว่าเป็นไฟล์เดิม ใช้อัปเดตลิงก์ในเมนูคลิกขวาเมื่อหมดอายุ ล้างรายการที่เสร็จจะลบเฉพาะประวัติ ไม่ลบไฟล์ งาน → ส่งออกรายการ… บันทึกรายการดาวน์โหลดเป็นไฟล์เพื่อสำรองหรือย้ายไปพีซีเครื่องอื่น งาน → นำเข้ารายการ… แสดงรายการใหม่ก่อนเพิ่ม ลิงก์ที่มีอยู่แล้วจะถูกข้าม และการดาวน์โหลดใหม่จะหยุดชั่วคราวไว้ มุมมอง → กล่องวางลิงก์แบบลอย จะแสดงกล่องเล็กที่อยู่เหนือหน้าต่างอื่นเสมอ วางลิงก์ลงไปเพื่อดาวน์โหลดได้ แม้ Download Engine อยู่ในถาดระบบ

## เว็บไซต์ออฟไลน์

### เว็บไซต์ออฟไลน์

### การเชื่อมต่อเบราว์เซอร์

ตัวแก้ไขและรายการสคริปต์ที่โหลดมีแท็บแยกกันแล้ว ค้นหาหรือสร้างสคริปต์ในรายการ และเปิดตัวแก้ไขแบบเต็มจากส่วนหัว Lua หรือ PowerShell ปุ่มบันทึก เรียกใช้/หยุด และบันทึกการทำงานแบบเลือกแสดงอยู่ร่วมกับโค้ด คำสั่งไฟล์อยู่ในเมนูการทำงานของตัวแก้ไข การสลับมุมมองจะเก็บโค้ดที่ยังไม่บันทึก การตั้งค่า และตำแหน่งเคอร์เซอร์ไว้


### สคริปต์

ในเครื่องมือ → สคริปต์ สร้างกฎตามไซต์หรือนามสกุล ในแท็บสคริปต์ เลือก Lua หรือ PowerShell บันทึกแล้วเรียกใช้ มีทริกเกอร์ด้วยตนเอง เมื่อเริ่มแอป ตามช่วงเวลา เมื่อดาวน์โหลดหรือคิวเสร็จ สคริปต์ไม่ทำงานทับตัวเอง การหยุดจบสคริปต์แต่ไม่ย้อนคำสั่งดาวน์โหลดที่ส่งแล้ว ดูผลในบันทึก

## สคริปต์ Lua

### สคริปต์ Lua

Lua มีในตัว สร้างสคริปต์ Lua แบบทริกเกอร์ด้วยตนเอง บันทึกและเรียกใช้ตัวอย่างด้านล่าง xd.queues() คืนคิว และ xd.downloads() คืนรายการดาวน์โหลด เหตุการณ์ดาวน์โหลดเสร็จใช้ event.downloads ส่วนคิวเสร็จใช้ event.queue อย่าแปลชื่อคำสั่งและฟิลด์ ดู API เพิ่มเติมใน docs/automation.md อย่าพิมพ์รหัสลับในบันทึก PowerShell ทำงานด้วยสิทธิ์บัญชี Windows ของคุณ

ตัวแก้ไข Lua และ PowerShell ตรวจสอบไวยากรณ์อัตโนมัติเมื่อหยุดพิมพ์ชั่วครู่ โดยไม่บันทึกหรือเรียกใช้สคริปต์ เพิ่มเลขบรรทัด สีไวยากรณ์ และข้อผิดพลาดที่คลิกเพื่อไปยังตำแหน่งได้ พิมพ์ส่วนต้นของชื่อหรือกด Ctrl+Space เพื่อดูคำแนะนำ เลือกด้วยลูกศร แทรกด้วย Tab, Enter หรือคลิก และปิดด้วย Esc รองรับการเลิกทำ ข้อผิดพลาดขณะทำงานยังอยู่ในบันทึก

```lua
print("Hello from Lua!")
print("Trigger:", event.trigger)
for _, queue in ipairs(xd.queues()) do
    print(queue.name, "running:", queue.running)
end
for _, file in ipairs(event.downloads) do
    print("Finished:", file.name or file.id)
end
```

ทริกเกอร์ ดาวน์โหลดล้มเหลว จะเรียกใช้สคริปต์เมื่อดาวน์โหลดยังต้องตรวจสอบหลังจากที่ Download Engine ลองใหม่อัตโนมัติแล้ว ซึ่ง event.downloads จะมี error ของแต่ละดาวน์โหลด xd.retry(id) และ xd.restart(id) ใช้ลองใหม่ (สคริปต์ทำได้ 5 ครั้งต่อดาวน์โหลด) xd.notify(title, text) แสดงการแจ้งเตือนของ Windows และ xd.store.get กับ xd.store.set เก็บค่าไว้ระหว่างการทำงานแต่ละครั้ง xd.rename, xd.move และ xd.remove จะเปลี่ยนไฟล์ได้เฉพาะเมื่อเปิด เปลี่ยนแปลงไฟล์ที่ดาวน์โหลดได้ ส่วน เรียกใช้ด้วยตัวอย่าง… ใช้ทดลองสคริปต์เหตุการณ์กับดาวน์โหลดที่คุณเลือก โดยการเปลี่ยนแปลงเป็นเพียงการจำลอง

```lua
for _, file in ipairs(event.downloads) do
    if pcall(xd.retry, file.id) then
        print("Retrying:", file.name or file.id)
    else
        xd.notify("Download still failing", (file.name or file.id) .. ": " .. (file.error or "no details"))
    end
end
local handled = (xd.store.get("handled") or 0) + #event.downloads
xd.store.set("handled", handled)
print("Failed downloads handled:", handled)
```

หากต้องการแก้ไขสคริปต์ในโปรแกรมอื่น ให้ใช้ เปิดไฟล์… และ บันทึกเป็นไฟล์… ที่ส่วนหัวของตัวแก้ไข เปิดไฟล์… จะคัดลอกไฟล์ .lua หรือ .ps1 ลงในตัวแก้ไข และจะถามก่อนหากจะแทนที่โค้ดที่ยังไม่บันทึก เลือก บันทึกสคริปต์ เพื่อเก็บไว้ ส่วน บันทึกเป็นไฟล์… จะเขียนโค้ดในตัวแก้ไขลงไฟล์

### Lua Core API 1

สร้างหรือเปิดสคริปต์ใน Loaded scripts แล้วเลือก Lua และ Manual only ใน Script settings ใช้ Full editor เพื่อขยายพื้นที่ จากนั้น Save script และ Run script แล้วดู Run logs ปุ่ม Core API แสดงฟังก์ชันของทริกเกอร์ปัจจุบัน และ Ctrl+Space เปิดคำแนะนำ API 1 เป็นรุ่นของสัญญา API ไม่ใช่รุ่นแอป ตัวอย่างนี้แยกวิเคราะห์ HTML ในหน่วยความจำเท่านั้น ไม่เชื่อมต่อหรือดาวน์โหลด การอ่านเว็บสำหรับสคริปต์แบบแมนนวลจะแสดง false

```lua
-- Example: core-api
assert(xd.api_version == 1, "This example needs Lua API 1")
print("App:", xd.app_version, "Role:", xd.script_kind)
local html = '<a class="download" href="/files/demo.zip">Demo</a>'
local links = xd.html_select(html, "a.download[href]", "href")
local url = xd.url_join("https://example.com/catalog/", links[1])
print("Preview:", xd.to_json({ kind = "file", url = url }))
print("Can fetch a page:", xd.supports("xd.fetch"))
```

Open examples/core-api-automation.lua or examples/custom-site-reader.lua with Editor actions → Open file…. Site reader uses public pages, Pages patterns and Direct connection; test with Test on URL before enabling its trigger. Ordinary automation cannot call xd.fetch. Import script… accepts .de-script.json as a new draft with automatic triggers and file changes off; review its code and reselect local queues. Stop script does not undo submitted downloads. ## การเชื่อมต่อ MCP

### การเชื่อมต่อ MCP

ในหน้า MCP เริ่มเซิร์ฟเวอร์ HTTP ภายในเครื่องแล้วคัดลอกการตั้งค่าไคลเอนต์ เริ่มด้วยโหมดดูอย่างเดียว AI ต้องมี URL และส่วนหัวการยืนยันตัวตนที่เป็นความลับ อย่าเผยแพร่โทเค็น หยุดเซิร์ฟเวอร์หรือเปลี่ยนโทเค็นเพื่อถอนสิทธิ์ ดู docs/mcp-ai-guide.md

ขณะนี้เปิด MCP เป็นหน้าต่างป๊อปอัปได้จากแถบเครื่องมือ เมนูเครื่องมือ หรือการตั้งค่า โดยไม่เปลี่ยนหน้าปัจจุบัน การปิดด้วย × หรือ Escape จะไม่หยุดเซิร์ฟเวอร์และยังเก็บการแก้ไข MCP ที่ไม่ได้บันทึกไว้ ใช้คำสั่งหยุดเซิร์ฟเวอร์เพื่อตัดการเชื่อมต่อไคลเอนต์ AI หากเปิดจากการตั้งค่า เมื่อปิดจะกลับไปยังการแก้ไขเดิม

## การสแกนไวรัส

โปรแกรมสแกน: Microsoft Defender, Malwarebytes, Kaspersky, Bitdefender, ClamAV.

ต้องมีการเชื่อมต่อ Explorer ภาษาอังกฤษของ โปรแกรมป้องกันไวรัส เวลาหมดอายุจำกัดเฉพาะส่งต่อ ยกเลิกสแกนใน โปรแกรมป้องกันไวรัส

ต้องใช้โฟลเดอร์ติดตั้งเริ่มต้น

แอปป้องกันไวรัสควบคุมการป้องกันและการกักกัน การส่งคำขอไม่ได้หมายความว่าไฟล์ปลอดภัย

ตรวจสอบการตั้งค่า: พบการผสานรวมแล้ว จะตรวจสอบความพร้อมเมื่อร้องขอสแกน

### การสแกนไวรัส

เปิด เครื่องมือ → สแกนไวรัส เลือก ไฟล์เดียว เพื่อสแกนไฟล์ที่ดาวน์โหลดเสร็จแล้วหนึ่งไฟล์ หรือ หลายไฟล์ เพื่อเลือกหลายรายการ ยกเลิกการสแกนไฟล์เดียวได้ แท็บจะถูกล็อกขณะสแกนหรือรอตรวจสอบผลใน Malwarebytes / Kaspersky / Bitdefender

เลือกตัวสแกนในตั้งค่าแล้วเปิดเครื่องมือ → สแกนไวรัส → หลายไฟล์ เลือกไฟล์ที่เสร็จ เริ่ม และดูผล หยุดจะยกเลิกคำขอที่ยังไม่ส่ง Malwarebytes / Kaspersky / Bitdefender รอให้คุณตรวจผลหลังแต่ละคำขอ การสแกนที่ส่งแล้วต้องหยุดใน Malwarebytes / Kaspersky / Bitdefender การส่งคำขอสแกนไม่ใช่การยืนยันว่าไฟล์ปลอดภัย

### การตั้งค่าและบันทึก

การตั้งค่ามีภาษา ธีม โฟลเดอร์ ความเร็ว โควตา พร็อกซี และจำนวนการเชื่อมต่อ บันทึกค้นหา กรอง คัดลอก เปิดโฟลเดอร์ และส่งออกข้อมูลวินิจฉัยได้ URL เส้นทาง ผลสคริปต์ และข้อผิดพลาดเทคนิคคงข้อความเดิม ตรวจรายงานก่อนแชร์

รุ่นติดตั้งจะตรวจสอบตำแหน่งโฟลเดอร์ Downloads ปัจจุบันของ Windows ทุกครั้งที่เริ่มทำงาน รวมถึงกรณีที่ย้ายไปไดรฟ์อื่น การดาวน์โหลดใหม่จะใช้ตำแหน่งนั้น ส่วนการดาวน์โหลดเดิม ความคืบหน้าที่บันทึกไว้ และโฟลเดอร์ที่กำหนดเองจะไม่เปลี่ยน รุ่นพกพาจะกำหนดโฟลเดอร์เริ่มต้นตามตำแหน่งแอปทุกครั้ง โปรไฟล์เดิมยังใช้ชื่อโฟลเดอร์ย่อย IDM EX หากไม่พบตำแหน่งจะแสดงข้อผิดพลาด

## การแก้ไขปัญหา

### การแก้ไขปัญหา

หากเชื่อมต่อไม่ได้ ตรวจว่าแอปทำงาน ID ส่วนขยายถูกต้องและลงทะเบียนแล้ว หลังอัปเดตให้โหลดส่วนขยายและหน้าใหม่ หากดาวน์โหลดล้มเหลว ตรวจพื้นที่ดิสก์ สิทธิ์โฟลเดอร์ พร็อกซี และลิงก์หมดอายุ อย่าลบข้อมูลกู้คืนก่อนลองทำต่อ หากอักษรเป็นกล่อง ให้เพิ่มฟอนต์ภาษาใน Windows แล้วเริ่มแอปใหม่
