## 3.0.2 — 2026-10-27

### Політика конфіденційності

Додано публічну політику щодо інтеграції з браузером, локального зберігання, необов’язкових файлів cookie для входу, зберігання й видалення даних, сторонніх інтеграцій та вимог обмеженого використання Chrome Web Store. Посилання доступні в README та посібнику з публікації розширень; копію включено до вихідного коду, розширень, переносних пакетів та інсталятора. Робота завантажень і дозволи не змінилися.

### Репозиторій вихідного коду та пакети випуску

Виконуваний файл FFmpeg більше не відстежується в репозиторії вихідного коду. Інсталятор і переносна версія й надалі містять його разом із відповідним вихідним кодом та ліцензійними повідомленнями. Вихідний код FFmpeg залишається в Git; інструкції зі збирання пояснюють, як отримати відповідний виконуваний файл.
