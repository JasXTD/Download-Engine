## 3.0.1 — 2026-10-27

### Піктограми розширень браузера

Розширення тепер містять логотип Download Engine у розмірах для панелі інструментів і магазину. Пакети Chrome, Edge, Brave та Firefox, інсталятор Windows і переносні версії містять однакові файли піктограм.

### Інструкції зі встановлення розширень

У README чітко зазначено, що схвалення магазинів розширень ще очікується. Chrome, Edge і Brave потребують режиму розробника та завантаження розпакованого розширення. У Firefox використовується тимчасовий додаток, який потрібно завантажувати знову після кожного перезапуску браузера. Розділ налаштування містить посилання на інструкції із завантаження та підключення для кожного браузера.
