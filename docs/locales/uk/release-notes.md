## 3.1.1 — 2026-10-27

### Швидше завершення великих файлів

Завантаження HTTP/HTTPS і FTP з однієї частини на одному диску тепер перевіряються та зберігаються без запису другої повної копії. Частини багатопотокових завантажень зберігають попередній асинхронний спосіб послідовного об’єднання. Для іншого диска використовується безпечне копіювання. Збережено перевірку контрольної суми, скасування, захист наявних імен і позначку походження з Інтернету. Перерване збереження відновлюється з готової частини або об’єднуваного файлу без повторного завантаження та дублікатів.
