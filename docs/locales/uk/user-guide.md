# Download Engine

## Початок роботи

Параметри відкриваються у вікні з категоріями. Зберегти застосовує зміни; Скасувати, × або Escape відкидає незбережені правки. Тему можна переглянути; скидання стосується лише поточної категорії. Розширені редактори зберігають окремо й після закриття повертають до Параметрів.

### Початок роботи

Виберіть «Додати URL», вставте пряме посилання, перевірте назву, чергу й папку та почніть завантаження. Пакет приймає по одному посиланню на рядок. «За шаблоном» створює нумеровані посилання на кшталт img001…img100 з одного посилання із *. Мову змінюють у Налаштування → Вигляд → Мова. Системна мова відповідає Windows; непідтримувана замінюється англійською.

## Завантаження та відновлення

### Завантаження та відновлення

Подвійне клацання по завантаженню відкриває прогрес, швидкість і залишок часу. Пауза й зупинення зберігають дані. Негайний запуск дає пріоритет вибраним файлам. Продовження потребує підтримки сервера й перевірки однаковості файлу. Прострочене посилання оновіть у контекстному меню. Очищення завершених прибирає лише історію, зберігаючи файли. Завдання → Експорт списку… зберігає завантаження у файл для резервної копії або перенесення на інший ПК. Завдання → Імпорт списку… перед додаванням показує нові елементи; наявні посилання пропускаються, а нові завантаження залишаються призупиненими. Вигляд → Плаваюче вікно перетягування показує невелике вікно поверх інших вікон; перетягніть на нього посилання, щоб завантажити їх, навіть коли Download Engine згорнуто в трей.

## Сайти офлайн

### Сайти офлайн

Збирач шукає файли або зберігає сайт офлайн. Задайте URL, глибину, ліміти сторінок і розміру, потім перегляньте результат. Відкрийте збережений index.html. Динамічні функції, вхід, форми й зашифроване відео не підтримуються. Пропуски вказано у звіті.

## Інтеграція з браузером

### Інтеграція з браузером

Відкрийте Інструменти → Налаштування браузера для Chrome, Edge, Brave або Firefox. Chrome, Edge і Brave потребують справжнього ID встановленого розширення. Перевірте з’єднання в його вікні. Параметри браузера мають окремий вибір мови. Відеокнопка відкриває вибір якості. Вхід сайту використовується лише для цього файлу після вашого дозволу.

## Черги та розклади

### Черги та розклади

Керування чергами групує файли й задає кількість одночасних завантажень. Нові черги чекають запуску або розкладу. Планувальник підтримує початок, зупинення й повторення. Застосунок має працювати, зокрема в треї. Вихід, вимкнення, сон і глибокий сон комп’ютера вмикають окремо; відлік можна скасувати.

## Скрипти

Редактор і завантажені скрипти тепер мають окремі вкладки. Шукайте та створюйте скрипти у списку, а повний редактор відкривайте із заголовка Lua або PowerShell. Збереження, запуск/зупинка й необов’язкові журнали розміщені поруч із кодом. Файлові команди перенесено в меню дій редактора. Зміна вигляду зберігає незбережений код, налаштування та позицію курсора.


### Скрипти

В Інструменти → Скрипти створіть правила за сайтом чи розширенням файлу. У скриптах виберіть Lua або PowerShell, збережіть і запустіть. Тригери: вручну, запуск застосунку, інтервал, завершення завантаження й черги. Скрипт не запускається поверх себе. Зупинення завершує скрипт, але не скасовує вже надіслані команди завантаження. Результат дивіться в журналі.

## Скрипти Lua

### Скрипти Lua

Lua вбудовано. Створіть Lua-скрипт із ручним тригером, збережіть і запустіть приклад нижче. xd.queues() повертає черги, xd.downloads() — завантаження. Завершення завантаження надає event.downloads, черги — event.queue. Назви команд і полів не перекладаються. Повний API: docs/automation.md. Не друкуйте секрети в журналах. PowerShell працює з правами вашого облікового запису Windows.

Редактори Lua та PowerShell автоматично перевіряють синтаксис після короткої паузи введення, не зберігаючи й не запускаючи скрипт. Додано номери рядків, підсвічування синтаксису та перехід до помилки натисканням. Введіть початок назви або натисніть Ctrl+Space, виберіть підказку стрілками та вставте через Tab, Enter або клацання. Esc закриває підказки. Підтримується скасування; помилки виконання залишаються в журналі.

```lua
print("Hello from Lua!")
print("Trigger:", event.trigger)
for _, queue in ipairs(xd.queues()) do
    print(queue.name, "running:", queue.running)
end
for _, file in ipairs(event.downloads) do
    print("Finished:", file.name or file.id)
end
```

Тригер «Помилка завантаження» запускає скрипт, коли завантаження все ще потребує уваги після автоматичних повторів Download Engine; тоді event.downloads містить error кожного завантаження. xd.retry(id) і xd.restart(id) повторюють спробу (скрипт може зробити це 5 разів для одного завантаження), xd.notify(title, text) показує сповіщення Windows, а xd.store.get і xd.store.set зберігають значення між запусками. xd.rename, xd.move і xd.remove змінюють файл, лише якщо ввімкнено «Може змінювати завантажені файли». «Запустити з прикладом…» перевіряє скрипт події на вибраних завантаженнях; зміни лише імітуються.

```lua
for _, file in ipairs(event.downloads) do
    if pcall(xd.retry, file.id) then
        print("Retrying:", file.name or file.id)
    else
        xd.notify("Download still failing", (file.name or file.id) .. ": " .. (file.error or "no details"))
    end
end
local handled = (xd.store.get("handled") or 0) + #event.downloads
xd.store.set("handled", handled)
print("Failed downloads handled:", handled)
```

Щоб редагувати скрипт в іншій програмі, використовуйте «Відкрити файл…» і «Зберегти у файл…» у заголовку редактора. «Відкрити файл…» копіює файл .lua або .ps1 у редактор і спершу питає, якщо при цьому заміниться незбережений код; виберіть «Зберегти скрипт», щоб зберегти його. «Зберегти у файл…» записує код із редактора у файл.

### Lua Core API 1

Створіть або відкрийте скрипт у Loaded scripts; виберіть Lua та Manual only у Script settings. Full editor розширює редактор; натисніть Save script, потім Run script і перегляньте Run logs. Core API показує функції поточного тригера, Ctrl+Space — підказки. API 1 є версією контракту, а не застосунку. Приклад аналізує HTML лише в пам’яті, без мережі та завантажень; доступність читання сторінок для ручного скрипту — false.

```lua
-- Example: core-api
assert(xd.api_version == 1, "This example needs Lua API 1")
print("App:", xd.app_version, "Role:", xd.script_kind)
local html = '<a class="download" href="/files/demo.zip">Demo</a>'
local links = xd.html_select(html, "a.download[href]", "href")
local url = xd.url_join("https://example.com/catalog/", links[1])
print("Preview:", xd.to_json({ kind = "file", url = url }))
print("Can fetch a page:", xd.supports("xd.fetch"))
```

Open examples/core-api-automation.lua or examples/custom-site-reader.lua with Editor actions → Open file…. Site reader uses public pages, Pages patterns and Direct connection; test with Test on URL before enabling its trigger. Ordinary automation cannot call xd.fetch. Import script… accepts .de-script.json as a new draft with automatic triggers and file changes off; review its code and reselect local queues. Stop script does not undo submitted downloads. Full English reference: docs/automation.md.

### Командний рядок

## Інтеграція MCP

### Інтеграція MCP

На сторінці MCP запустіть локальний HTTP-сервер і скопіюйте налаштування клієнта. Почніть із режиму перегляду. ШІ потрібні URL і секретний заголовок авторизації. Не публікуйте токен. Зупиніть сервер або змініть токен для відкликання доступу. Докладніше: docs/mcp-ai-guide.md.

MCP тепер відкривається у спливному вікні з панелі інструментів, меню «Інструменти» або налаштувань, зберігаючи поточну сторінку. Закриття через × або Escape не зупиняє сервер і зберігає незбережені зміни MCP. Щоб від’єднати клієнтів ШІ, зупиніть сервер. Якщо вікно відкрито з налаштувань, закриття повертає до тієї самої чернетки.

## Антивірусна перевірка

Сканер: Microsoft Defender, Malwarebytes, Kaspersky, Bitdefender, ClamAV.

Потрібна англійська інтеграція антивірусі із Провідником. Час обмежує передавання, не перевірку. Скасовуйте перевірку в антивірусі.

Потрібна стандартна папка встановлення.

Захистом і карантином керує антивірус. Запит не означає відсутності загроз.

Перевірити налаштування: Інтеграцію знайдено; доступність сканування перевіряється під час запиту.

### Антивірусна перевірка

Відкрийте Інструменти → Перевірка антивірусом. «Один файл» дозволяє вибрати одне завершене завантаження, «Пакет» — кілька. Окреме сканування можна скасувати. Вкладки заблоковані під час сканування й очікування перегляду результатів Malwarebytes / Kaspersky / Bitdefender.

Виберіть антивірус у налаштуваннях, потім Інструменти → Перевірка антивірусом → Пакет. Виберіть готові файли, запустіть і перегляньте результати. Зупинення скасовує ненадіслані запити. Malwarebytes / Kaspersky / Bitdefender чекає вашої перевірки після кожного запиту. Вже передані перевірки зупиняйте в Malwarebytes / Kaspersky / Bitdefender. Надісланий запит не означає безпечність файлу.

## Налаштування та журнали

### Налаштування та журнали

Налаштування охоплюють мову, тему, папки, швидкість, квоти, проксі й кількість з’єднань. Журнали можна шукати, фільтрувати, копіювати та експортувати. URL, шляхи, вивід скриптів і технічні помилки зберігають початковий текст. Перевіряйте звіт перед поширенням.

Встановлена версія під час кожного запуску запитує поточну папку завантажень Windows, зокрема перенесену на інший диск. Нові завантаження використовують це розташування. Наявні завантаження, збережений прогрес і вибрані папки не змінюються. Переносна версія щоразу визначає папку відносно програми. Старі профілі зберігають назву підпапки IDM EX. Якщо розташування визначити не вдалося, з’являється помилка.

## Усунення несправностей

### Усунення несправностей

За помилки з’єднання перевірте запуск застосунку, ID розширення й реєстрацію. Після оновлення перезавантажте розширення та сторінку. За помилки завантаження перевірте диск, права папки, проксі й строк посилання. Не видаляйте дані відновлення до спроби продовження. Якщо замість літер квадрати, додайте мовні шрифти Windows і перезапустіть застосунок.
