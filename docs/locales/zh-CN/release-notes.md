## 3.15.0 — 2026-11-06

### Lua 提供器核心与 ASS 字幕

Lua HTTP 新增 HEAD、PUT、PATCH、DELETE 和 OPTIONS 方法、受大小限制的二进制请求体，以及由提供器显式提供并绑定到单一来源的会话。凭据在解析器之外保持加密，不写入下载计划，也不传给离线处理器。媒体计划支持未知分段大小；lua_stream 以有界数据块处理分段，并通过验证过的检查点支持暂停、恢复、停止和故障恢复。

新增由操作系统保护的二进制和 RSA 凭据导入、随机字节、SHA-1/SHA-256、HMAC、RSA 签名与解密，以及 AES 数据块解密。ASS 字幕在 MKV 中保留样式和行内覆盖，在 MP4 中转换为文本字幕。使用新凭据或媒体功能的配置需要支持写入版本 9 的应用；原有检查点格式仍兼容。

离线 CENC 作者实验使用 Lua 解析有限的 AVC/AAC 样本加密子集，演示模拟的已签名许可证交换、密钥交接，以及将解密后的轨道与 ASS 字幕封装。站点认证、许可证格式和容器解析仍由 Lua 代码实现。验证使用生成的数据，不使用真实服务或账户；这不是完整的 CENC 实现。

### 种子共享与搜索

已完成种子的共享现在会在分享率达到 2.0 或共享满一周时自动停止，以先到者为准。此功能默认开启，现有配置同样适用；两项上限均可在偏好设置 → 种子中修改或关闭。下载期间的上传也计入分享率。状态窗口会显示分享率；因达到上限而停止的种子会保留文件，并在其菜单中提供再次共享。

没有 Tracker 的磁力链接不再被直接拒绝。添加下载窗口会说明：DHT 搜索会让其他计算机看到您想要哪个种子以及您的 IP 地址；只有点击在 DHT 中搜索后才会开始搜索。只有在经过校验的文件列表确认这是公开种子后，才会把您的计算机宣告为节点。私有种子会使搜索停止，单次搜索最多持续 10 分钟。来自浏览器、剪贴板或资源管理器的链接绝不会自行搜索。

新增自动设置路由器 (UPnP)，与其所需的传入连接一样默认关闭。它只与私有网络中的默认网关通信，只申请一条每次有效一小时的端口转发规则，并且只删除自己的规则；在 macOS 上显示为不可用。找到的节点和 DHT 节点若使用其他服务的端口（1024 以下，以及 SIP 5060 等端口），永远不会被连接。因 DHT 原因停止的下载现在会以所选语言显示原因。

## 3.5.1 — 2026-10-29

### Lua 提供程序安全性

- 解析/刷新与转换/结束在权限分离的工作进程中运行。处理进程在加载源码时也无法使用 `xd.fetch`。使用 `xd.phase` 区分初始化阶段；解析阶段的局部变量不会传入处理阶段。
- 保存的计划仅保留大小、哈希和转换标识，解析得到的 URL 按需刷新。任务固定的源码由当前 Windows 用户的 DPAPI 保护。旧任务以原子方式升级，保留检查点绑定，并阻止旧版写入。
- `xd.key` 和从重定向标准输入读取密钥的 `scripts protect-key` 命令提供与提供程序绑定的不透明 AES 密钥句柄。私钥无需写入源码或导出文件；历史备份和库中现有的密钥字面量不会被清除。详见 `docs/lua-providers.md`。

### 清除历史记录

清除已完成的历史记录前会显示确认窗口，列出队列和已完成数量。取消或关闭窗口不会清除记录；已下载的文件始终保留。
