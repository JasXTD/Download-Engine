## 3.6.0 — 2026-10-31

### 扩展

新的“扩展”页面取代“脚本”页面，包含“已安装”“脚本”“规则”和“运行历史”选项卡。一个扩展就是一个 .de-extension.json 文件，可打包站点读取器、下载提供程序和自动化任务。目前只能从本地文件安装，发布者未经验证。安装前会显示它能做什么，安装后默认关闭，更新需要新权限时必须先询问。其网络访问仅限于它声明的主机。安装第一个扩展后，旧版应用不能再写入此配置文件。

## 3.5.2 — 2026-10-30

### 启动时检查更新

默认在每次打开程序时检查一次。发现新版本后可选择获取更新或稍后处理。离线时不会弹出错误，可在偏好设置中关闭此选项。 请从官方 GitHub 发布页面下载并安装更新。

## 3.5.1 — 2026-10-29

### Lua 提供程序安全性

- 解析/刷新与转换/结束在权限分离的工作进程中运行。处理进程在加载源码时也无法使用 `xd.fetch`。使用 `xd.phase` 区分初始化阶段；解析阶段的局部变量不会传入处理阶段。
- 保存的计划仅保留大小、哈希和转换标识，解析得到的 URL 按需刷新。任务固定的源码由当前 Windows 用户的 DPAPI 保护。旧任务以原子方式升级，保留检查点绑定，并阻止旧版写入。
- `xd.key` 和从重定向标准输入读取密钥的 `scripts protect-key` 命令提供与提供程序绑定的不透明 AES 密钥句柄。私钥无需写入源码或导出文件；历史备份和库中现有的密钥字面量不会被清除。详见 `docs/lua-providers.md`。

### 清除历史记录

清除已完成的历史记录前会显示确认窗口，列出队列和已完成数量。取消或关闭窗口不会清除记录；已下载的文件始终保留。

## 3.5.0 — 2026-10-29

### Lua Provider API 1

新增 Lua 下载提供程序：解析文件、处理字节、校验哈希并使用常规下载队列暂停和恢复。每个任务保留已保存的脚本版本。示例仅使用本地生成的加密文件验证。保存提供程序后，旧版应用不能再写入此配置文件。

## 3.4.1 — 2026-10-29

下载列表减少了大型队列的重复复制和搜索开销。小窗口为文件名留出更多空间，搜索控件可适应可用宽度。可在队列状态旁启动或暂停队列；启动会覆盖其计划。悬停在状态上可查看重试说明和错误。下载传输、校验和续传格式保持不变。

## 3.4.0 — 2026-10-29

### 主题集

偏好设置 → 外观 → 自定义提供 Neon Courier、Reactor Night、Aurora 和 Moonveil 主题。可调整背景强度与强调色，或导入 PNG/JPEG。保存以保留预览，取消以恢复原外观。图片仅存于本地，导入有大小限制并在后台运行。
