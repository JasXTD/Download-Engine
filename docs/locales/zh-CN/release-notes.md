## 3.2.0 — 2026-10-28

### 公共网盘链接

新增 MEGA 公共单文件和 WeTransfer 公共传输支持。MEGA 在本地解密并验证完整性；在服务器与文件标识允许时，可安全暂停和续传。

不支持受密码保护、仅限账户或已失效的传输；MEGA 文件夹不受支持。

### 下载页面文件发现与浏览器捕获

下载页面可发现公开文件链接；不明确或跨站的选择需要确认。浏览器扩展保留 MEGA 密钥并支持 GitHub 原始文件下载操作。升级后请重新加载扩展。

### 网站与文档

网站新增视频支持说明、网页抓取预览、网盘功能介绍和截图轮播。

安装包和便携包继续包含 FFmpeg、对应源代码及许可证。

帮助菜单新增手动检查 GitHub 稳定版更新、重试和发行页面链接。关于页面现已链接到官方 GitHub 仓库。
