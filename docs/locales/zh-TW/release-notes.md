## 3.2.0 — 2026-10-28

### 公開網盤連結

新增 MEGA 公開單一檔案和 WeTransfer 公開傳輸支援。MEGA 會在本機解密並驗證完整性；伺服器與檔案識別允許時，可安全暫停與續傳。

不支援密碼保護、僅限帳戶或已失效的傳輸；MEGA 資料夾不受支援。

### 下載頁面檔案探索與瀏覽器擷取

下載頁面可探索公開檔案連結；不明確或跨站的選擇需要確認。瀏覽器擴充功能保留 MEGA 金鑰並支援 GitHub 原始檔案下載操作。升級後請重新載入擴充功能。

### 網站與文件

網站新增影片支援說明、網站擷取預覽、網盤功能介紹和截圖輪播。

安裝程式和可攜套件繼續包含 FFmpeg、對應原始碼與授權文件。

說明選單新增手動檢查 GitHub 穩定版更新、重試與發行頁面連結。關於頁面現已連結到官方 GitHub 儲存庫。
