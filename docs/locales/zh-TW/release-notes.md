## 3.5.2 — 2026-10-30

### 啟動時檢查更新

預設在每次開啟程式時檢查一次。發現新版本後可選擇取得更新或稍後處理。離線時不會彈出錯誤，可在偏好設定中關閉此選項。 請從官方 GitHub 發行頁面下載並安裝更新。

## 3.5.1 — 2026-10-29

### Lua 提供者安全性

- 解析/重新整理與轉換/結束在權限分離的工作程序中執行。處理程序在載入原始碼時也無法使用 `xd.fetch`。使用 `xd.phase` 區分初始化階段；解析階段的區域變數不會傳入處理階段。
- 儲存的計畫僅保留大小、雜湊與轉換識別碼，解析得到的 URL 會按需更新。工作固定的原始碼由目前 Windows 使用者的 DPAPI 保護。舊工作以不可分割的方式升級，保留檢查點綁定，並阻止舊版寫入。
- `xd.key` 與從重新導向的標準輸入讀取金鑰的 `scripts protect-key` 指令，提供綁定至提供者的不透明 AES 金鑰控制代碼。私密金鑰無需寫入原始碼或匯出檔；歷史備份及程式庫中現有的金鑰常值不會被清除。詳見 `docs/lua-providers.md`。

### 清除歷史記錄

清除已完成的歷史記錄前會顯示確認視窗，列出佇列和已完成數量。取消或關閉視窗不會清除記錄；已下載的檔案始終保留。

## 3.5.0 — 2026-10-29

### Lua Provider API 1

新增 Lua 下載提供者：解析檔案、處理位元組、驗證雜湊，並使用一般下載佇列暫停與繼續。每個工作保留已儲存的指令碼版本。範例僅以本機產生的加密檔案驗證。儲存提供者後，舊版應用程式無法再寫入此設定檔。

## 3.4.1 — 2026-10-29

下載清單減少了大型佇列的重複複製與搜尋負擔。小視窗為檔名保留更多空間，搜尋控制項可配合可用寬度。可在佇列狀態旁啟動或暫停佇列；啟動會覆寫其排程。將游標停在狀態上可查看重試說明與錯誤。下載傳輸、驗證與續傳格式維持不變。

## 3.4.0 — 2026-10-29

### 主題集

偏好設定 → 外觀 → 自訂提供 Neon Courier、Reactor Night、Aurora 和 Moonveil 主題。可調整背景強度與強調色，或匯入 PNG/JPEG。儲存以保留預覽，取消以還原原外觀。圖片僅存於本機，匯入有大小限制並在背景執行。
