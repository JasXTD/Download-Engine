## 3.15.0 — 2026-11-06

### Lua 提供器核心與 ASS 字幕

Lua HTTP 新增 HEAD、PUT、PATCH、DELETE 和 OPTIONS 方法、具大小限制的二進位請求本文，以及由提供器明確提供並綁定至單一來源的工作階段。認證資訊在解析器之外維持加密，不寫入下載計畫，也不傳給離線處理器。媒體計畫支援未知的分段大小；lua_stream 以有界資料區塊處理分段，並透過經過驗證的檢查點支援暫停、繼續、停止及故障復原。

新增由作業系統保護的二進位與 RSA 認證資訊匯入、隨機位元組、SHA-1/SHA-256、HMAC、RSA 簽署與解密，以及 AES 區塊解密。ASS 字幕在 MKV 中保留樣式與行內覆寫，在 MP4 中轉換為文字字幕。使用新認證資訊或媒體功能的設定檔需要支援寫入版本 9 的應用程式；原有檢查點格式仍相容。

離線 CENC 作者實驗以 Lua 解析有限的 AVC/AAC 樣本加密子集，示範模擬的已簽署授權交換、金鑰交接，以及將解密後的軌道與 ASS 字幕封裝。網站驗證、授權格式和容器解析仍由 Lua 程式碼實作。驗證使用產生的資料，不使用真實服務或帳戶；這不是完整的 CENC 實作。

### 種子分享與搜尋

已完成種子的分享現在會在分享率達到 2.0 或分享滿一週時自動停止，以先到者為準。此功能預設開啟，現有設定檔同樣適用；兩項上限皆可在偏好設定 → 種子中修改或關閉。下載期間的上傳也會計入分享率。狀態視窗會顯示分享率；因達到上限而停止的種子會保留檔案，並在其選單中提供再次分享。

沒有 Tracker 的磁力連結不再直接遭到拒絕。新增下載視窗會說明：DHT 搜尋會讓其他電腦看到您想要哪個種子以及您的 IP 位址；只有按下在 DHT 中搜尋後才會開始搜尋。只有在經過驗證的檔案清單確認這是公開種子後，才會將您的電腦公告為節點。私人種子會使搜尋停止，單次搜尋最多持續 10 分鐘。來自瀏覽器、剪貼簿或檔案總管的連結絕不會自行搜尋。

新增自動設定路由器 (UPnP)，與其所需的傳入連線一樣預設關閉。它只與私人網路中的預設閘道通訊，只申請一條每次有效一小時的連接埠轉送規則，並且只移除自己的規則；在 macOS 上顯示為無法使用。找到的節點和 DHT 節點若使用其他服務的連接埠（低於 1024，以及 SIP 5060 等連接埠），絕不會被連線。因 DHT 原因停止的下載現在會以所選語言顯示原因。

## 3.5.1 — 2026-10-29

### Lua 提供者安全性

- 解析/重新整理與轉換/結束在權限分離的工作程序中執行。處理程序在載入原始碼時也無法使用 `xd.fetch`。使用 `xd.phase` 區分初始化階段；解析階段的區域變數不會傳入處理階段。
- 儲存的計畫僅保留大小、雜湊與轉換識別碼，解析得到的 URL 會按需更新。工作固定的原始碼由目前 Windows 使用者的 DPAPI 保護。舊工作以不可分割的方式升級，保留檢查點綁定，並阻止舊版寫入。
- `xd.key` 與從重新導向的標準輸入讀取金鑰的 `scripts protect-key` 指令，提供綁定至提供者的不透明 AES 金鑰控制代碼。私密金鑰無需寫入原始碼或匯出檔；歷史備份及程式庫中現有的金鑰常值不會被清除。詳見 `docs/lua-providers.md`。

### 清除歷史記錄

清除已完成的歷史記錄前會顯示確認視窗，列出佇列和已完成數量。取消或關閉視窗不會清除記錄；已下載的檔案始終保留。
